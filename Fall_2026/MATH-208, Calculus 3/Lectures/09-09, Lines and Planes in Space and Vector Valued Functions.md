In gneeral, the circle of radius R centered at (a, b) can be parametrized by $<a,b>+R<\cos(t),\sin(t)> = <a+R\cos(t),b+R\sin(t)>$. If you need to find the bounds, just plug the start and end point into the parametrized equation and put it in terms of pi.

To determine if <mark style="background: #BBFABBA6;">two vector-valued functions collide</mark>, set the same variable (x,y,z) parametrized equations equal to each other and solve for t. Plug that t value into the other equations and if the t value makes ALL the corresponding components equal, the objects collide
To determine if <mark style="background: #BBFABBA6;">two vector-valued functions cross</mark> (different time, same place), set the components equal to each other, swap out one sides t's for s's, and solve the systeam of linear equations using substitution and elimination to find the values for t and s. Plug these solved t and s values into the z component and if the two sides are equal, the paths intersect
