<mark style="background: #BBFABBA6;">Data Models</mark> (data structure) represents what the actual data goes through while the <mark style="background: #BBFABBA6;">Process Model</mark> (functions) shows the flow of the process at a very high level

The <mark style="background: #BBFABBA6;">Database Management System (DBMS)</mark> should do:
1. Data collection and processing
2. Data representation
3. And be able to restructure the data

The application process will take care of data visualization and data analysis and data communication must be capable of transmission, security, and I/O 

The phases of data modeling are <mark style="background: #ADCCFFA6;">1. conceptual model 2. logical model and 3. physical model</mark>
