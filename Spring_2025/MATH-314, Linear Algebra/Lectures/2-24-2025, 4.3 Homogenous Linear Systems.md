## Homogenous Linear Systems
A SOL is called <mark style="background: #ADCCFFA6;">homogenous</mark> if all of the constant terms are zero
	It is not possible for a homogenous term to be inconsistent because the trivial solution (all variables = 0) will always be a solution

<mark style="background: #BBFABBA6;">In general, solution sets of homogenous systems are equal to some span</mark>

## Associated Homogeneous Systems
Given any linear system Ax = b, the system Ax = 0 is called the <mark style="background: #ADCCFFA6;">associated homogenous system</mark>

For example,
$$A=\begin{bmatrix}
1 & 2 & 4 \\
3 & -7 & -1 \\
-1 & 4 & 2
\end{bmatrix}\text{and }b=\begin{bmatrix}
-2 \\
7 \\
-4
\end{bmatrix}$$
Solving Ax = b so you just set b as the = part of the augmented matrix and solve like normal

Solves to RREF:
$$\begin{bmatrix}
1 & 0 & 2 & | & 0 \\
0 & 1 & 1 & | & -1 \\
0 & 0 & 0 & | & 0
\end{bmatrix}$$
Notice that the z column is free, so set it equal to t
$$\begin{matrix}
x=-2t \\
y=-t-1 \\
z=t
\end{matrix}$$
So, the solution in SOL x form is
$$\overrightarrow{x}=\begin{bmatrix}
0 \\
-1 \\
0
\end{bmatrix}+\begin{bmatrix}
-2 \\
-1 \\
1
\end{bmatrix}t$$
Notice: from a previous example where we solved Ax = 0, this is the same thing except for the constant term. <mark style="background: #BBFABBA6;">The slope is the same (what you multiply t by)</mark>. These are parallel lines. The Ax = 0 line goes through the origin and this one does not

<mark style="background: #BBFABBA6;">The Ax = 0 system gives the direction of the system (kind of like an intercept), and the Ax = b solution gives the actual location</mark>. They will always share the same slope, the constants are different

## Particular and General Solutions
In the previous example, the vector [0 -1 0]^T is an example of a <mark style="background: #ADCCFFA6;">particular solution</mark>
We can find any number of particular solutions by setting t to different values. If a solution is just a multiple of another solution, it is still a solution
	For example, t = 3 corresponds to the particular solution [-6 -4 3]

Note: [0 -1 0]^T is just a horizontal version of the column vector $\begin{bmatrix}0 \\ -1 \\ 0\end{bmatrix}$. Transposing things just means make the rows columns and sometimes it's easier to write it horizontal

Solutions of Ax = b are of the form:
$\overrightarrow{x}=(\text{any particular solution of Ax=b})+(\text{general solution of Ax=0})$

Suppose $x_{p}$ is a particular solution to Ax = b
1. If $x_{h}$ is a solution to Ax = 0, then $x_{p}+x_{h}$ is a solution to Ax = b
2. Every solution of Ax = b is of the form $x_{p}+x_{h}$
