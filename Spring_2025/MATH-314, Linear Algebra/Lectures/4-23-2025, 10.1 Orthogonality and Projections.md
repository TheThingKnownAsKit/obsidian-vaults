## Dot Product
Recall that if the dot product of two vectors is 0 then they are orthogonal

## Orthogonal and Orthonormal Sets
Let $\{v_{1},v_{2},\dots,v_{k}\}$ be a set of nonzero vectors in $\mathbb{R}^n$. This set is called <mark style="background: #ADCCFFA6;">orthogonal</mark> if $\overrightarrow{v}_{i}*\overrightarrow{v}_{j}=0$ for all $i\neq j$

Moreover, if $||\overrightarrow{v}_{i}||=1$ for $i=1,\dots,k$, then we say the set is <mark style="background: #ADCCFFA6;">orthonormal</mark>
![[Pasted image 20250423174257.png]]

<mark style="background: #ADCCFFA6;">Normalizing</mark> an orthogonal set is the process of turning an orthogonal set into an orthonormal set
If $\{v_{1},v_{2},\dots,v_{k}\}$ is orthogonal then the set $\left\{\frac{1}{||\overrightarrow{v}_{1}||}\overrightarrow{v_{1}},\frac{1}{||\overrightarrow{v}_{2}||}\overrightarrow{v_{2}},\dots,\frac{1}{||\overrightarrow{v}_{n}||}\overrightarrow{v_{n}}\right\}$ is orthonormal

## Orthogonal Projection onto a Subspace
Suppose W is a subspace of $\mathbb{R}^n$ with orthogonal basis $\{f_{1},f_{2},\dots,f_{m}\}$
Then the vector $\overrightarrow{w}=proj_{W}\overrightarrow{x}=\frac{\overrightarrow{x}*\overrightarrow{f_{1}}}{\overrightarrow{f_{1}}*\overrightarrow{f_{1}}}\overrightarrow{f_{1}}+\dots+\frac{\overrightarrow{x}*\overrightarrow{f_{m}}}{\overrightarrow{f_{m}}*\overrightarrow{f_{m}}}\overrightarrow{f_{m}}$ is called the <mark style="background: #ADCCFFA6;">orthogonal projection</mark> of x onto W

## Orthogonal Decomposition
We can <mark style="background: #ADCCFFA6;">decompose</mark> a vector x into the sum of its projection $w=proj_{W}x$ and the vector orthogonal to w, which we call $w^{\bot}$ (said w-perp)

Let W be a subspace of $\mathbb{R}^n$ with basis $\{f_{1},f_{2},\dots,f_{m}\}$

Theorem: $w^{\bot}$ is orthogonal to every
1. $f_{i,j}=1,2,\dots,m$ and
2. every vector in W
