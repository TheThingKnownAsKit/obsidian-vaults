## Singular and Nonsingular Matrices
An n x n square matrix A is called <mark style="background: #ADCCFFA6;">non-singular</mark> provided that RREF (A) = $I_{n}$ Otherwise A is <mark style="background: #ADCCFFA6;">singular</mark>
![[Pasted image 20250224093950.png]]
If the RREF is the identity matrix

The following statements are equivalent for an n x n matrix A:
1. A is nonsingular
2. Ax = b has a unique solution for any b in $\mathbb{R}^n$
3. Ax = 0 has only the trivial solution x = 0 (<=> columns if A are linearly independent)
