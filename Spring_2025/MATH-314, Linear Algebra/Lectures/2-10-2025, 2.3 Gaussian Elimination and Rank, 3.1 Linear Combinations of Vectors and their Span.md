## Gaussian and Gauss-Jordan Elimination
The process of row reducing a matrix to REF is called <mark style="background: #ADCCFFA6;">Gaussian elimination</mark>
Row reducing a matrix to RREF is called <mark style="background: #ADCCFFA6;">Gauss-Jordan elimination</mark>

![[Pasted image 20250210094005.png]]
Starting from i = 1 for every iteration. i refers to rows
1. (Find the pivot column) Find the first column from the left containing a nonzero entry in row i or below row i
2. (Find the leading entry/pivot a) in the pivot column beginning with row i, pick the topmost nonzero entry as a. If a is not in row i, switch rows so that a moves to row i
3. (Gauss-Jordan Elimination) Multiply the row containing a by 1/a to make the leading entry a 1. Optional if only doing Gaussian
4. (Subtract below leading entry) Subtract multiples of the row containing a from the rows below it, make each entry BELOW a zero
5. Set i = i + 1 (increasing the row)

## Linear Combinations
A vector v is a <mark style="background: #ADCCFFA6;">linear combination</mark> of vectors $v_{1},v_{2},\dots,v_{n}$ if $\overrightarrow{v}=a_{1}\overrightarrow{v_{1}}+a_{2}\overrightarrow{v_{2}}+\dots+a_{n}\overrightarrow{v_{n}}$ for some scalars a1, a2, ..., an
Basically a vector can be written as a linear combination if given weights with scalars
