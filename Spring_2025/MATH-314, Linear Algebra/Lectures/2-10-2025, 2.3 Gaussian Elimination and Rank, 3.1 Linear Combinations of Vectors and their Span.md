## Rank
The <mark style="background: #ADCCFFA6;">rank</mark> of a a matrix A, denoted rank(A), is the number of nonzero rows in a REF of A. <mark style="background: #BBFABBA6;">The rank is used to determine how many solutions a SLE might have, if any</mark>
	The row has to be completely 0 to be a zero row

Suppose a system of m equations in n variables is consistent, and the the rank of the coefficient matrix is r.
1. The set of solutions involves exactly n - r parameters, corresponding to n - r free variables
2. If r < n, the system has infinitely many solutions
3. If r = n, the system has a unique solution
