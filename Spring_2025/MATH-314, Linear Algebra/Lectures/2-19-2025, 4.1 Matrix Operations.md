## Matrices
A <mark style="background: #ADCCFFA6;">matrix</mark> is a rectangular array of numbers. The dimension of a matrix is m x n where m is the rows and n is the columns
A <mark style="background: #ADCCFFA6;">column vector</mark> in $\mathbb{R}^n$ is m x 1 matrix
A <mark style="background: #ADCCFFA6;">row vector</mark> in $\mathbb{R}^n$ is a 1 x n matrix
The (i, j) entry is the entry in the ith row and jth column

We call a matrix with the same number of rows as columns <mark style="background: #ADCCFFA6;">square</mark>

![[Pasted image 20250219123734.png]]
The entries a_ii lie on the <mark style="background: #ADCCFFA6;">main diagonal</mark> of the matrix A

The m x n <mark style="background: #ADCCFFA6;">zero matrix</mark> denoted as O is the matrix with every entry equal to 0

## Addition and Scalar Multiplication
Let $A=\begin{bmatrix}a_{ij}\end{bmatrix}$ and $B=\begin{bmatrix}b_{ij}\end{bmatrix}$ be m x n matrices

We say A = B if a_ij = b_ij for all 1 <= i <= m and 1 <= j <= n

The sum of matrixes A and B is $A+B=[a_{ij}+b_{ij}]$
	You literally just add them

The scalar product of k and A is $kA=[ka_{ij}]$
	You literally just multiply it

## Transpose of a Matrix
The <mark style="background: #ADCCFFA6;">transpose</mark> of an m x n matrix A is the n x m matrix
$$A^T=([a_{ij}])^T=[a_{ji}]$$

A matrix is <mark style="background: #ADCCFFA6;">symmetric</mark> if $A^T=A$
A matrix is <mark style="background: #BBFABBA6;">diagonal</mark> if every entry outside of the main diagonal is zero
