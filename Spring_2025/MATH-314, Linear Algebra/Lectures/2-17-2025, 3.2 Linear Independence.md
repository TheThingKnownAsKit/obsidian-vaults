## Redundant Vectors
We call the vector $v_{i}$ in a set of vectors $\{v_{1},\dots,v_{i},\dots,v_{k}\}$ <mark style="background: #ADCCFFA6;">redundant</mark> if we can remove it without changing the span of the set

## Linear Independence
Let $v_{1},v_{2},\dots,v_{k}$ be vectors in $\mathbb{R}^n$. The set $\{v_{1},\dots,v_{k}\}$ is <mark style="background: #ADCCFFA6;">linearly independent</mark> if the only solution to the linear combination equation
$$c_{1}\overrightarrow{v_{1}}+c_{2}\overrightarrow{v_{2}}+\dots+c_{k}\overrightarrow{v_{k}}=\overrightarrow{0}$$
is the <mark style="background: #ADCCFFA6;">trivial solution</mark> $c_{1}=c_{2}=\dots=c_{k}=0$

If there is a <mark style="background: #ADCCFFA6;">nontrivial solution</mark> (not all c's are zero) to the linear combination equation, then we say that the set is <mark style="background: #ADCCFFA6;">linearly dependent</mark>

## Determining Linear Independence
1. Write down a matrix whose columns are the vectors and row reduce to a REF
	1. If there is a pivot in every column of the REF, it is linearly independent
	2. If there is one or more column that does not have a pivot, the vectors are linearly dependent
	3. Alternatively, if you row reduce to RREF and there is any free variables, it is dependent
	4. Any set containing the zero vector is linearly dependent (before REF)

Note: matrices with more columns than rows are almost always dependent. More rows than columns can just cancel out the extra rows to 0
