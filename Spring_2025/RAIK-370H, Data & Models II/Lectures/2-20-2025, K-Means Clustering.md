## Supervised and Unsupervised ML
<mark style="background: #ADCCFFA6;">Supervised learning</mark> means there are features and labels, and we know the labels of all the data. The algorithm is trained to identify labels given a set of features
	Naive Bayes, Decision Tree, and K-Nearest Neighbor are all supervised

<mark style="background: #ADCCFFA6;">Unsupervised learning</mark> is when you want to explore and learn about data without having labels

## K-Means Clustering
Goal: Given a set of data, identify regions or groupings within the data. A group means having similar feature values
