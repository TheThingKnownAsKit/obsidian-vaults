Quiz output of the scheme code `(let ((a 1) (b (+ a 1)) (+ a b))` = D. error because let does local binding in parallel

let is shorthand for a lambda function

let* does binding in sequence

letrec evaluates expression from left to right but generate all identifiers before they actually do the evaluation

Use
```Scheme
(lambda
	(letrec ... ))
```
If the nested function needs to know about one of the arguments to the outer function
Use
```Scheme
(letrec
	(lambda ...))
```
If the nested function does not need to know about one of the arguments to the outer function (because it takes it as an argument itself)
