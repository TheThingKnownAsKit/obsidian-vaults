## Imperative Languages
<mark style="background: #ADCCFFA6;">Imperative Languages</mark> are most dominant because of von Neumann  computers. It is where data and programs are stored in memory, memory is separate from CPU, and instructions and data are piped from memory to CPU
1. Variables model memory cells
2. Assignment statements model piping operations
3. Iteration is efficient
