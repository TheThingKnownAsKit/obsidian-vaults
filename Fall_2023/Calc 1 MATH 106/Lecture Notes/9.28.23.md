## Mean Value Theorem
If f is continuous function on the interval [a, b] and differentiable on the interval (a, b), then there exists a number c, with a < c < b. such that
	$f'(c)=\frac{f(b)-f(a)}{b-a}$
In other words, $f(b)-f(a)=f'(c)(b-a)$
It's an *if, then* mathematical theorem. *Remember that the mean value theorem only works if the function is differentiable EVERYWHERE on the interval. Watch out for discontinuities and cusps/corners/vertical tangent lines.* You can make it apply by not including the discontinuities/other differentiable elements in the interval.
The left hand side is the slope of the tangent line, and the right hand side is the slope of the secant line. It is saying that there is some point c between a and b where the slope of the secant line is equal to the slope of the tangent (they're parallel).

To find the c, first find the derivative of f'(c), then set it equal to whatever the slope of the secant is. *THEN, DONT FORGET TO CHECK IF C IS IN THE INTERVAL*
$f(x)=x^3+x-1$
$f'(c)=3c^2+1$
On the interval [0, 3],
$\frac{(3^3+3-1)-(0^3+0-1)}{3-0}=\frac{30}{3}=10$
$3c^2+1=10$
$3c^2=9$
$c^2=3$
$c=\pm \sqrt3$
However, $-\sqrt3$ is not in the interval [0, 3], so the only c that satisfies the mean value theorem is $\sqrt3$

NOTE: If given no function and just a graph, find the secant slope first. c is the x value where the slope of the function is the secant slope.
	So, if $\frac{f(b)-f(a)}{b-a}=0$ then c is where the slope of the function is 0.
NOTE: *A function can not satisfy the HYPOTHESES of the Mean Value Theorem because of discontinuities, but it can satisfy the CONCLUSION if the values just so happen to not include the discontinuities.*

## The Increasing Function Theorem
Suppose that f is continuous on $a \le x \le b$ and differentiable on $a < x < b$.
* If f'(x) > 0 on a < x < b, then f is increasing on $a \le x \le b$.
* If f'(x) $\ge 0$ on a < x < b, then f is non-decreasing on $a \le x \le b$

## The Constant Functions Theorem
Suppose that f is continuous on $a \le x \le b$ and differentiable on a < x < b.
If f'(x) = 0 on a < x < b, then f is constant on $a \le x \le b$

## The Racetrack Principle
Suppose that g and h are continuous on $a \le x \le b$ and differentiable on a < x < b, and that g'(x) $\le$ h'(x) for a < x < b.
* If g(a) = h(a), then g(x) $\le$ h(x) for $a \le x \le b$
* If g(b) = h(b), then g(x) $\ge$ h(x) for $a \le x \le b$
To understand this theorem think of a 100 meter race between Gary (g) and Harry (h). Here a = 0 and b = 100. Note that Harry is always faster than Gary. There are two scenarios to consider: They both are together at the start or they are both together at the finish.
If they both start together then Harry will always be ahead of Gary throughout the race because Harry is faster.
If they both finish together then Harry was behind Gary throughout the race until Harry caught up with Gary at the end of the race.

You can use the Racetrack Principle to establish inequalities.
Example: Use the Racetrack Principle to show that $\ln(x) \le x-1$ for all $x\ge 1$.
$g'(x)=\frac 1x$
$h'(x)=1$
When $x\ge1$, then $\frac 1x \le 1$, so $g'(x) \le h'(x)$
$g(1)=\ln(1)=0$
$h(1)=1-1=0$
So, by the Racetrack Principle, $g(x) \le h(x)$ for all $x \ge 1$
$g(x) \le h(x)$
$\ln(x) \le x - 1$ for $x\ge 1$
