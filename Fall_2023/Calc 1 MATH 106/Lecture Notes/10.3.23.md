## Local Maximum or Minimum
#### Definition of local max/min and critical points
We say that f has a *local (or relative) maximum* at p with local maximum value f(p) if f(p) >= f(x) for all x near p. Likewise, *local (or relative) minimum* at p with local minimum value f(p) whenever f(p) <= f(x) for all x near p.

Remember that local mins/maxes are only valid if the function actually stops, not if it continues up/down infinitely. (like x^2 has a min but no max)
	Unless you restrict the domain.

If f is defined on an interval and has a local max or min at the point x = p, then
* p is an endpoint of the interval or
* f'(p) is undefined or
* f'(p) = 0
In the last two cases (p, f(p)) is a critical point.
*NOT EVERY LOCAL MAX OR MIN IS A CRITICAL POINT*
![[IMG_1926.jpg]]

We say that a function f has a *critical point* at (p, f(p)) provided that p is in the domain of f, and
* f'(p) = 0 or
* f' (p) is undefined
	It needs to be about to switch directions or stop.
When (p, f(p)) is a critical point, we say that p is a *critical number* of the function, or that f(p) is a *critical value*.

#### The First Derivative Test for Local Maxima and Minima
If p is a critical number of a continuous function f that is differentiable near p (except possibly at x = p), then
* f has a local maximum at p if and only if f' changes sign from positive to negative at p
* f has a local minimum at p if and only if f' changes sign from negative to positive at p
* If the sign does not change then it is not a local extrema
![[IMG_1927.jpg]]

#### The Second Derivative Test for Local Max and Min
If p is a critical number of a continuous function f such that f'(p) = 0 and f''(p) != 0, then:
* f has a local max at p if and only if f''(p) < 0
	* Concave down
* f has a local min at p if and only if f''(p) > 0
	* Concave up
Look at the picture above, same applies. The graph on the left is concave down, the one on the right is concave up.
There's not really any reason to use the second derivative test over the first test unless you're only given the second or if somehow the second derivative is easier to work with because you don't need a calculator (just use a calculator).
#### Solving for local extrema
Combine extrema classifications with the first/second derivative test to *find the local extrema*.
* Set the derivative equal to 0 and solve
	This should give you a set of terms that if zero, the entire thing will be zero. Separate these and see what they'd solve to if = 0. This is also a good check for finding undefined locations.
	This gives you the x location of the point, put the x back into the ORIGINAL function to find y and get the full point (x, y).
* Look at the endpoints (if there are any)
	You can't use the first/second derivative test on the endpoints because there's nothing on the other side / not in the domain. But you can check one side to see if it's a max/mi]n. If the one side is positive, it's likely a min. 
STEP TWO: Check the left and right hand side of the points found, see how the sign changes. Or use second test.

## Concavity and Inflection Points
Let f be a continuous function. If p is a point in the domain of f at which f changes concavity, then we say that (p, f(p)) is an *inflection point* (or *point of inflection*) of f.
If f'' is defined on both sides of a point p:
* If f'' is zero or undefined at p, then p is a POSSIBLE inflection point
* To test whether p is an inflection point, check whether f'' changes sign around this point. If the sign does change, it is an inflection point.
