## Dominance: Polynomials and Exponentials
A function g(x) *dominates* a function f(x) as x -> infinity provided
$\lim_{x\to \infty} \frac{f(x)}{g(x)}=0$
This means that g(x) grows faster than f(x) when x -> infinity. In the situation aboive we also say that g(x) is *dominant*.

Exponentials are most dominant. Higher exponent. (e^x). Anything with e^x will probably be the most dominant
Power functions next. x^something
Log functions last
Example: Arrange in order by dominance as x -> infinity. from least to most.
1. $x^{100}$
2. $x(\ln(x))^2$
3. $\frac{e^{2x}}{x}$
4. $x^2$
5. $e^x\ln(x)$
Correct order is 3, 5, 1, 4, 2
## Parametric Equations
Example:
Object moving around in a circle.

Consider the angle t that the radius forms with the edge of the circle. Makes a right triangle. 
$x(t) = cos(t)$
$y(t)=sin(t)$
Need to model something moving in multiple directions at once with two equations.
This is the parametric equation for a unit circle. (circle centered on the origin with radius 1)

This is a *parametric* equation. It is an equation in which a third variable is introduced to represent a curve in the plane. 

Example:
Consider the path of an object that is propelled into the air at an angle of 45 degrees. The object's height y would be given by:
$y=-\frac{x^2}{72}+x$
This equation does not tell the whole story. It tells where it has been, it does not tell you when it was at any given point. To fix this, introduce a third variable.
$x=24\sqrt{2}t$
$y=-16t^2+24\sqrt{2}t$

*Given the parametric equations x(t) and y(t) for a curve, we may determine the slope of the tangent line to the curve for any values of t as follows:*
$\frac{dy}{dx}=\frac{dy/dt}{dx/dt} \to \frac{\frac{dy}{dt}}{\frac{dx}{dt}}$

For example:
Find the tangent line at the point (1,2) to the curve defined by the parametric equations:
$x=t^3, y=2t$
It is $\frac{2}{3t^2}$
However, this is not the end. Slope needs to be a NUMBER, not the equation. Find the value of t where x = 1 and y = 2 for the point (1,2). This value is 1
Final is $2\over3$
