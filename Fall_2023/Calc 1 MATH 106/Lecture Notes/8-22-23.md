**Function & Function Notation**
A function f is a rule that assigns to each input x a unique output denoted f(x) or y.

F : Domain -> Codomain, f(x) = rule
- Domain = the collection of all inputs
- Codomain = the collection of all possible outputs
- Range = the collection of all actual outputs

The vertical line test is my best friend. One x value cannot have multiple y outputs.

**Linear Function**
A linear function is a function of the form y = mx + b where m is the slope and b is the y-intercept.

**Increasing/Decreasing/Monotonic Functions**
A function is increasing if the values of f(x) increase as x increases.
A function is decreasing if the values of f(x) decrease as x increases.
A function is monotonic if it either increases for all x or decreases for all x. (linear function)

**Function Operations**
Multiplying a function by a constant, c, that is y = cf(x), stretches the graph vertically (if c > 1) or shrinks the graph vertically (if 0 < c < 1)
A negative sign (if c < 0) reflects the graph about the x-axis.
Adding k to the output, y = f(x) + k, moves a graph up by k or down by k if it is negative.
Subtracting k from the input, y = f(x - k), moves a graph to the right by k and to the left if k is negative. (opposite)

**Invertible Functions**
A function f has an inverse if for every value y in the range there is exactly one value x such that y = f(x). It has to pass both the vertical and horizontal line test. No two inputs can have the same output.

**Inverse Functions**
If the function f is invertible, its inverse is defined as follows f^-1(y) = x means y = f(x)
*It is not the reciprocal*
You flip x and y and perform the opposite operation on y. (don’t think this is super reliable on more complex functions)
So f(x) = sqrt(x) --> f^-1(y) = y^2
In graphing terms, you can just swap the x and y value for coordinate points. You basically reflect it about a 45 degree angleish.

*Concavity*
The graph of a function is concave up if it bends upward as we move left to right, it is down if it bends down.

*Exponential Function*
An exponential function is a function of the form
P(t) = P0a^t.
- P0 is the initial quantity, or the y-intercept (when t = 0)
- a is the growth/decay factor. Note: decay is 0 < a < 1, not negative numbers (decimals). Growth is a > 1, because if a is one then it is a line.
- t stands for time
