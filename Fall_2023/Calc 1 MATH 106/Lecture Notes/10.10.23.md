## Practical tips for modeling optimization problems
1. Draw a picture and introduce variables (names) for quantities in the picture.
2. Identify the quantity to be optimized as well as any key relationships (constraints) among the variable quantities
3. Determine a function of a single variable that models the quantity to be optimized. To do so, you may need to solve for the other variable in the constraint and plug it into the objective. Identify the domain for the function to be optimized
4. Find the critical values and evaluate the function at these points and the endpoints (if relevant) to find the global max and/or min
5. Look back - reflect on the answer and verify it solves the problem being asked. (if it doesn't make sense for the answer to be negative, it can't be an answer)

#### Example:
A kennel owner wants to enclose a rectangular area adjoining an existing building, and then divide it into 3 equally shaped pens for his dogs with fencing parallel to the wall of the building. The kennel owner has 1400 meters of fencing available to complete the job. What is the largest possible total area of the 3 pens?

1. Draw a picture. Pretend this is a picture not a table

| Building |
| -------- |
| Pen 1 (x)    |
| Pen 2 (x)    |
| Pen 3 (x)    |

2. Identify quantities and key relationships
x = Length of the fence parallel to the building
y = length of the fence perpendicular to the building (the left and right walls)

3. Maximize area, so use area formula of a rectangle.
$MaxArea = xy$  <--- The objective function
Subject to the fact that $3x + 2y = 1400$   <--- constraint
	The amount of fencing each wall is taking must be equal to 1400, the max amount of fencing available.

Solve so it's equal to only one variable.
$y = \frac{1400 - 3x}{2}$
$Area = x * \frac{1400 - 3x}{2}$ -> $700x - \frac{3}{2}x^2$

Maximize $f(x)=700x - \frac{3}{2}x^2$ on [0, 1400/3]
You cannot have negative fencing and no one x can be greater than one third of 1400.

4. Find the critical points.
$f'(x)=700-3x$
$700-3x=0$ -> $\frac{700}{3}=x$

The endpoints are x = 0 and $x=\frac{1400}{3}$ 

| x               | f(x)                                              |
| --------------- | ------------------------------------------------- |
| 0               | 0                                                 |
| $\frac{700}{3}$ | $\frac{700^2}{6}$ |
| $\frac{1400}{3}$  | 0                                                  |
So the answer is, at the largest area, the maximum is $\frac{700^2}{6}$ for $x=\frac{700}{3} * y=\frac{700}{2}$
