                                                         # Fundamental Theorem of Calculus
F(b) - F(a) = [Total change in F(t) between t = a and t = b]
$\int_a^bF'(t)dt$
In words, the definite integral of a rate of change gives the total change.

**Theorem (The Fundamental Theorem of Calculus, or FTC)**
If f is continuous on the interval [a, b] and f(t) = F'(t), then $\int_a^bf(t)dt=F(b)-F(a)$
Since the terms being added up are products of the form ''F(t) times a difference in t," the units of $\int_a^bf(t)dt$ is the product of the units of f(t) and the units of t.

# Antiderivatives
If the derivative of F is f, we call F an **antiderivative** of f.
The antiderivative of 2x is x^2. Technically there's more than one because constants cannot be determined. This is the **family of antiderivatives**.
	$\frac{d}{dx}(x^2+C)=2x$ where c is any constant real number
If an initial condition is specified (the value of the value at a specific point/value), then you can determine C

## Finding Antiderivatives
We write families of antiderivatives as an **indefinite integral.** That is, if $F'(x) = f(x)$ then $\int f(x)dx=F(x)+C$. It has no bounds

This means any function of the form F(x) + C (where C is a real number) is an **antiderivative** of f(x).
If H'(x) = 0 on an interval, then H(x) = c on this interval for some constant C.
If F and G are both antiderivatives of f on an interval, then G(x) - F(x) = C.

## Properties of Antiderivatives
**Sum Rule**
Let f and g be functions that have antiderivatives and c a constant, then 
$\int (f(x)\pm g(x))dx=\int f(x)dx\pm \int g(x)dx$
Integral of two functions added/minused is just their integrals added/minus

**Constant Multiple**
$\int cf(x)dx = c \int f(x)dx$
You just move the c in front of the integral

**Antiderivatives of Powers of x**
If k is a constant, than $\int kdx = kx + C$ since $\frac{d}{dx}(kx) = k$.
$\int x^ndx=\frac{x^{n+1}}{n+1}+C$ when n != -1 since divide by zero.
Basically, add 1 to the exponent and divide it by exponent + 1
Antiderivative of $x^3$ is $\frac{x^4}{4}+C$

**Antiderivatives of Other Functions**
 $\int (e^x)dx=e^x + C$
$\int cos(x)dx=sin(x) + C$
$\int sin(x)dx = -cos(x)+C$

NATURAL LOG ONLY FOR POSITIVE NUMBERS
$\int \frac{1}{x}dx=ln(x)+C$
NATURAL LOG ONLY FOR NEGATIVE NUMBERS
$\int \frac{1}{x}dx=ln(-x)+C$
# Integral Function
If f is a continuous function, we define the corresponding **integral function** A according to the rule $A(x) = \int_a^xf(t)dt$.
Note that A(x) is a measure of the amount of area accumulated beneath the graph of the function f.

The parameter a:
$A(x) = \int_a^xf(t)dt$
Notice that no restrictions are imposed on the parameter a in the integral function. Any value of a results in an area accumulation function, but what does the parameter a control?
* Suppose a = 0, then what is the value of A(0)?
	* 0
* If a = 2, what is the value of A(2)?
