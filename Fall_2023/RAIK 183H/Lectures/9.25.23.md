## Arrays
Declared by `<type>[] <name> = new <type>[<length>];`
#### Default values of arrays
| Type                     | Default value    |
| ------------------------ | ---------------- |
| int                      | 0                |
| double                   | 0.0              |
| boolean                  | false            |
| String (or other object) | null (no object) | 
#### Array memory
The new keyword always mean new memory. It allocates consecutive memory in the required bit amount.

Indexes in arrays can be accessed by multiplying 32 (or bits in a different type, this is for int) * array index and putting that to the end of the total array memory address. Not in actual code but processing wise.  
	So like to find the 2nd index (3rd overall item it starts at 0), you'd do the memory address of array + 32 * 2
		ABCDEFGH64
Because of this simple math to find the exact location of the data we want, arrays are very fast.

For thing's with indeterminate and potentially very large memory requirements (Strings/Any non-primitive), the array is actually an array of addresses to a random spot in memory with the data.
The processor has no idea how many characters a String will hold or if you're going to edit it later, so it can't store the data in the array itself.

#### Limitations of Arrays
Benefit of arrays: very fast
Downfall:
	immutable
	You cannot resize an existing arrays
	You cannot compare arrays with == or equals
	An array does not know how to print itself

These are attempted to be fixed with the ARRAYS class
| Method name                    | Description                             |
| ------------------------------ | --------------------------------------- |
| copyOf(<array>, <length>)      | returns a new copy of an array          |
| equals(<array1>, <array2>)     | returns true if same elements/order     |
| fill(<array>, <value>)         | sets every element to the given value   |
| toString(<array>)              | returns a string of the array           |
| sort(<array>)                  | arranges the elements into sorted order |
| binarySearch(<array>, <value>) | returns the index of given value        |
