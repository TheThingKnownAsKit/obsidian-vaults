# Sorting Algorithms
```
public static void swap(int[] arr, int index1, int index2) {
	int temp = arr[index1];
	arr[index1] = arr[index2];
	arr[index2] = temp;
}
```

Bubble, Selection, and insertion are all pretty much interchangeable in terms of performance.
Bubble is not very good at all really (good for already sorted arrays to just verify it's sorted, same for insertion). Selection is NOT good for verifying a sorted array since it'd just swap everything with itself.
But all of them are in the mediocre category. In worst case (reverse order), selection sort is better.
Because of the randomness and variability, usually interchangeable.

All **quadratic** algorithms. It will look at elements $n^2$ times.
**Linear** would look at every element once.
## Bubble Sort
Look at all adjacent pairs of elements and swap them if they're out of order. Do this n times (where n is the length of the array)
Largest values "bubble" up to the end of the list, vice versa with smallest.
Most comparisons, will have n amount of swaps
Number of comparisons is always (n-1)^2
```
static void bubbleSort(int[] arr) {
	for (int i = 0; i < arr.length - 1; i++) {
		for (int j = 1; j < arr.length; j++) {
			if (arr[j-1] > arr[j]) {
				swap(arr, j-1, j);
			}
		}
	}
}
```
Outer loop is to ensure it loops for n times, inner loop actually does the checks
## Selection Sort
Look at all unsorted elements, find the minimum element, swap it to be in the last position of the sorted list.
You "select" the next smallest element to be added to the sorted portion of the list.
Will always have a number of swaps of n if the list is length n. No matter the list length.
Less swaps more comparisons
```
public static void selectionSort(int[] arr) {
	for (int i = 0; i < arr.length; i++) {
		int currentMinIndex = i;
		for (int j = i + 1; j < arr.length; j++) {
			if (arr[j] < arr[currentMinIndex]) {
				currentMinIndex = j;
			}
		}
		swap(arr, currentMinIndex, i)
	}
}
```
## Insertion Sort
Take the first un-sorted element to the right of the sorted list and swap it left until it is in the appropriate sorted position. Sorts lowest values to the left.
You "insert" each new element into the appropriate spot in the sorted array.
More swaps less comparisons
```
public static void insertionSort(int[] arr) {
	for (int i = 0; i < arr.length; i++) {
		int j = i + 1;
		while (j > 0 && arr[j] < arr[j-1]) {
		swap(arr, j-1, j);
		j--;
		}
	}
}
```
