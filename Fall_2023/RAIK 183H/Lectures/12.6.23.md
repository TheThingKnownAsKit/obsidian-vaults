## Image Icon
An **ImageIcon** allows you to put a picture on a button, label, or other component.
`ImageIcon imageIcon = new ImageIcon(String filename);`
`ImageIcon imageIcon = new ImageIcon(URL address);`

Most component's we've talked about so far have a constructor that accepts an ImageIcon. There's also the `setIcon(Icon)` and `setSelectedIcon(Icon)` for a new image once it's selected. Or `setRolloverIcon(Icon)` for when it's hovered over.

## JScrollPane
A **JScrollPane** is a special container that holds a component, using scrollbars to allow that component to be seen.
If the component is bigger than the thing, it will scroll.
`JScrollPane jScroll = new JScrollPane(Component comp);`
`frame.add(new JScrollPane(area), BorderLayout.CENTER);`

## JColorChooser
A **JColorChooser** is a special dialog box that lets the user pick from a palette of colors.
`JColorChooser jColor = new JColorChooser(optional initial Color);`
Remember it's a DIALOG.

## JCheckBox, JRadioButton
A **JCheckBox** is a list of boxes you can click. More than one is clickable.
A **JRadioButton** is a list of options with circles as their 'boxes'. You can only select ONE of these. Or this is the usual, not required I don't think.

`JCheckBox checkBox = new JCheckBox(String text);` for the label. Same for JRadioButton.
`thing.isSelected();` and `thing.setSelected(boolean selected);`

## ButtonGroup
A logical group of radio buttons that ensures that only one is selected at a time. It is NOT a component and NOT a visual thing. Purely logic.

`ButtonGroup bGroup = new ButtonGroup();`
`bGroup.add(button);`

## JComboBox
It is a drop down box.
`JComboBox dropDown = new JComboBox(Object[] items);`
You have to add an action listener for when the user selects or types a new item in the combo box.

`get/setSelectedIndex()`
`get/setSelectedItem()`
`setEnabled()`
`setEditable`

# Laying Out Components
There are different ways to do layouts.

**Absolute Positioning** (C++, C#, others)
	Specify exact pixel coordinates for every component

**Layout Managers** (Java)
	Have special objects that decide where to position each component based on some criteria.

## Layout Managers
Kind of like templates. You can mix and match.
You can add Layout managers to Layout managers for specific regions or something.

List of managers:
* BorderLayout (default)
	* Divides container into five regions (NORTH, SOUTH, WEST, EAST, CENTER)
	* NORTH and SSOUTH regions expand to fill region horizontally and use preferred size vertically
	* WEST and EAST expand to fill region vertically and use preferred size horizontally
	* Center uses all space not occupied
* Grid layout (consistent sizes in a grid)
* Flow layout (adds things from left to right)
	* Follows preferred size both horizontally and vertically
	* Wraps to next line if out of room
	* Can specify if you want padding (in pixels) or for the elements to be centered `new FlowLayout(FlowLayout.CENTER, 15, 20)`
* Box layout (flow but vertical)
	* Disregards preferred size
	* Can specify 0 rows or columns to indicate expansion in that direction as needed
* GridBag layout (yes)
	* Just don't do, it's complicated
* CardLayout
	* Layers of "cards" stacked on top of each other, one visible at a time.
	* Never used really

## Containers
A **container** is an object that holds components; it also governs their positions, sizes, and resizing behavior.
* `add(Component comp)`
* `add(Component comp, Object info)`
	* Adds a component to the container, possibly giving extra info about where to place it.
* `remove(Component comp)`
* `setLayout(LayoutManager mgr`
	* How to position components
* `validate()`
	* Call this if you make changes to the contents of a container that is already on the screen. This will make it re-do its layers. Sometimes Java does this by itself but sometimes not.
	* Equivalent to setVisible really
