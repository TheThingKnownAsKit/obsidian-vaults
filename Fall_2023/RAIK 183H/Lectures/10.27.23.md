## ArrayList
An *ArrayList* is a List with an underlying array. You can insert/add/remove/sort elements in an ArrayList. It's main con compared to regular arrays is it takes up A LOT more memory/processing power.
Generally in programming languages, when an ArrayList runs out of room it will increase its size by 50% + 1.
	arr.length + arr.length / 2 + 1
		For example, a length of 10 would increase to 16
		If you only added one to an ArrayList of length 10, the size would be 11 and the length would be 16.

*In ArrayLists, length != size*
The capacity of the underlying array is always > or = to the number of elements to the number of elements in the array (the size)
The *length* is the number of slots available in the array, and *size* is the number of elements actually stored in it.
When created, they default to 10 elements.
However, if you try to access a value that exists length wise but not size wise, you'll get an error. Just use add.

There's an ArrayList constructor that allows you to put in a different ArrayList to make a copy of it. 

Note: The `remove(index)` method actually returns the value it removes. You don't have to use the return value.

## Generics
`ArrayList<Type> name = new ArrayList<Type>();`
When constructing an ArrayList, you must specify the type of elements it will contain between < and >.
Class's can accept parameters but only of type and not of variable. This is called a *type parameter or generic class*. That's what the <> are for. It CANNOT be primitive types, only reference. (Integer, Double, String, an object, etc)
Adding generics means that you can have a variable of unknown type, and once initialized with type, it'll become that type.
	You can have a variable Tree with unknown type, but if you do `<String>` then Tree will now be a String variable.
	Instead of having to write an ArrayList class for every type, they only had to write one with generics.
