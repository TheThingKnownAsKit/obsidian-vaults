## Object abstraction and security
*Encapsulation:* Hiding implementation details from clients.
It forces *abstraction*.
* separates external view (behavior) from internal view (state)
* protects the integrity of an object's data
Basically only shares the Javadoc comments.

For reference types, sometimes you should return a copy of the array and not the array itself. It depends on the case. If you *don't need the original, send a copy* just to be safe.

*Invariants* are requirements that can constrain an objects state.
Examples with an accounting book:
* Example: Only allow `Accounts` with a non-negative balance are valid (you can't have negative money)
* Example: Only `Dates` with a month from 1-12

## Comparing objects
When you make a class, there's some syntactic sugar here, it's actually writing:
`public class IPad extends Object {...}`
* Inherits object methods and properties
* Methods like toString(), equals(), and hashCode()

For methods that accept Object parameters, they SHOULD be an object from the same class.

Custom objects WILL NOT have a default compareTo function. If you want to compare for more than just equality, make this yourself.
* Necessary for using Arrays.sort() or similar
The method signature needs to be exactly:
`public int compareTo(Object object) {...}`

***JUST ADDING THAT FUNCTION ISN'T ENOUGH***
You MUST also add `implements Comparable` to the class declaration
`public class ComparingExample implements Comparable {..}`
Another way is `public class ComparingExample implements Comparable<Town> {..}`
This allows you to accept ONLY a specific object type, not just an object so you don't have to cast in the `compareTo()` method. Sometimes useful sometimes not.

You MUST cast the accepted object into the desired object. Basically, a regular Object will not have all the properties of the custom object you've made. It's a parent with base level features. Casting it to the desired object type will allow it to use those properties and methods of the custom object.
Remember this method is part of an object class. You're calling this method on an object, so you only need one parameter. Use `this` to specify.
```
public int compareTo(Object object) {
	Town otherTown = (Town)object;
	// returns positive number when this object is greater than the other
	// returns zero when equal
	// returns negative when this object is less than other

	if (this.mayor.length() > otherTown.getMayor().length()) {
		return 1;
	} else if (this.mayor.length() == otherTown.getMayor().length()) {
		// Utilizes the String compareTo method. If equal, sort alphabetically
		return this.mayor.compareTo(otherTown.getMayor());
	} else if (this.mayor.length() > otherTown.getMayor().length()) {
		return -1;
	}
}
```
