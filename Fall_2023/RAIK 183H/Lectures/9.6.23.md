## Formatting With printf
Format of printf calls:

`System.out.printf(format string, list of parameters);`
The format string is a string in quotes, with special format symbols inserted:
%d specifies an int
%c specifies a character
%s specifies a String  
%f specifies a floating point type

Consider the format symbols to be "fill-in-the-blanks" spots in the format string. These are filled in with the list of parameters.
You can put a normal string before the %. Inputs variables into the string without needing to concatenate.
`System.out.printf("There are %d students\n", numStudents);
`System.out.printf("Juan's course grade was %c, and his GPA is %f\n", letterGrade, gpa);`

To specify how many decimal places for the output of a floating point value, modify the %f symbol in this format:
%.Nf // where N is the number of decimal places
% is starting place, f is end
NOTE THIS ROUNDS THEM

You can also specify how many digits it HAS to be. If there are not enough digits, it will add 0's to the left. You can also do %numd without a 0 which will fill it will spaces instead. Put a 0 in front of the desired digits to fill with 0's, if you don't it will fill with spaces. If the entered number has MORE digits than specified, it will just return something with more digits, it will not cut it off. (not talking abt decimals)
You can ask it to specify if it's positive or negative using + (don’t use - for this). One of the needed digits will be taken up by a sign, the rest will fill with whatever you specified.
You can ask it to separate the number with a comma every 3 digits. This takes up a digit slot.
```
int n = 461012
System.out.printf("%08d", n); // --> 00461012
System.out.printf("%+8d", n); // -->  +461012
System.out.printf("%,8d", n); // -->  461,012
System.out.printf("%+,8d", -n); // --> -461,012
```
