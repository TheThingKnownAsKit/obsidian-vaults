## Mouse and Keyboard Events
### Mouse Events
Mouse:
* Listen to clicks
* Listen to movement within a GUI component (panel)
* Respond to mouse activity
* Create interactive programs
```JAVA
public interface MouseListener {
	public void mouseClicked(MouseEvent event); // a short click
	public void mouseEntered(MouseEvent event);
	public void mouseExited(MouseEvent event);
	public void mousePressed(MouseEvent event); // clicked but in two parts
	public void mouseReleased(MouseEvent event); // think drag and drop etc
}
```
An **interface** is a list of behaviors a class will be able to do.

```JAVA
public class MyMouseListener implemenets MouseListener {
	public void mouseClicked(MouseEvent event) {}
	public void mouseEntered(MouseEvent event) {}
	public void mouseExited(MouseEvent event) {}
	// Need to implemenet all the methods even if theyre empty
	
	public void mousePressed(MouseEvent event) {
		System.out.println("User pressed mouse button!");
	}
	
	public void mouseReleased(MouseEvent event) {}
}
```

```JAVA
JPanel panel = new JPanel();
panel.addMouseListener(new MyMouseListener());

-or-

panel.addMouseListener(new MouseListener() {
	public void mouseClicked(MouseEvent event) {}
	public void mouseEntered(MouseEvent event) {}
	public void mouseExited(MouseEvent event) {}
	// Need to implemenet all the methods even if theyre empty
	
	public void mousePressed(MouseEvent event) {
		System.out.println("User pressed mouse button!");
	}
	
	public void mouseReleased(MouseEvent event) {}
});
```
Instantiating the behavior WHEN it's created inside the listener. 
Note: these are going to get long.

### MouseEvent Object
**THE MOUSTEVENT OBJECT**
* `public int getClickCount()`
* `public Point getPoint()` where exactly the click happened
* `public int getX() -or- getY()`
* `public Object getSource()` returns the object that was clicked on

**SwingUtilities**
* `boolean isLeftMouseButton(MouseEvent event)`
* `boolean isRightMouseButton(MouseEvent event)`

```JAVA
public void mousePressed(MouseEvent event) {
	Point p = event.getPoint();
	Object source = event.getSource();
	if (source == myPanel && p.getX() < 10) {
		JOptionPane.showMessageDialog(null,
			"You clicked the left side of myPanel!");
	}
}
```

### Keyboard Events
Usage of keyboard events:
* Listen to keyboard activity within a GUI component (panel)
* Responds to activity
* Control onscreen drawn characters and simulate text input

```JAVA
public interface KeyListener {
	public void keyPressed(KeyEvent event); // ANY key is pressed. No capitals only lowercase if its a letter
	public void keyReleased(KeyEvent event);
	public void keyTyped(KeyEvent event); // When the key can be converted into a unicode character (so like not shift)
}
```

### KeyEvent Objects
* `public int getKeyCode()` returns the int value of key constants below. Only works for keyTyped
* `public char getKeyChar()` works for both
* `public Object getSource()`

Included as constants such as VK_A, VK_Z, VK_0, VK_9, etc

```JAVA
JPanel panel = new JPanel();
panel.addKeyListener(new KeyListener() {
	public void keyTyped(KeyEvent event) {
		char keyChar = event.getKeyChar();
		int keyCode = event.getKeyCode();
		
		if (keyCode == KeyEvent.VK_ESCAPE) {
			System.exit(0);
		} else if (keyChar == 'a') {
			addNewThing();
		}
	}
	public void keyPressed(KeyEvent event) {}
	public void keyReleased(KeyEvent event) {}
});
```

```JAVA
JPanel panel = new JPanel();
panel.addKeyListener(new KeyListener() {
	public void keyPressed(KeyEvent event) {
		char key = event.getKeyChar();
		
		if (key >= 'a' && key <= 'g') {
			startPlayingNote(char key);
		} 
	}
	public void keyTyped(KeyEvent event) {}
	public void keyReleased(KeyEvent event) {
		char key = event.getKeyChar();
		stopPlayingNote(char key);
	}
});
```

# Timers
Execute action multiple times.
Create animations in GUI.

A timer is an example of a **callback** where the code starts the timer, then later at a specified time, the timer activates, causing an event.

`public Timer(int ms_delay, ActionListener al`
Causes an event every ms_delay milliseconds.

Things it can do:
* `start()` starts the timer, it will not do this automatically
* `stop()` more like a pause
* `restart()` 
* `addActionListener(ActionListener al)` you can add another al if you want
* `public boolean isRunning()`
* `public void setDelay(int delay)`
* `public void setInitialDelay(int delay)` one time delay to occur before ticking starts
* `public void setRepeats(boolean b)` does this repeat or only fire once?

```JAVA
int DELAY = 100;

ActionListener updater = new ActionListener() {
	public void actionPerformed(ActionEvent event) {
		somevar++;
		myPanel.repaint(); // kind of like validate. re-render
	}
}

Timer tim = new Timer(DELAY, updater);
tim.start();
```

```JAVA
int DELAY = 1000 * 10;

Timer tim = new Timer(DELAY, new ActionListener() {
	public void actionPerformed(ActionEvent event) {
		callNextBingoBall();
	}
});

tim.start();
```
