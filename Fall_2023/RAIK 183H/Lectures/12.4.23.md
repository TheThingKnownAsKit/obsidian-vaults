## Graphical Input and Output With JOPTIONPANE
An **option pane** is a simple dialog box for graphical input/output
* Advantage
	* Simple
	* Flexible (kinda)
	* Looks better than the console
	* Interrupts user flow (sometimes good sometimes bad)
* Disadvantages
	* Created with static methods; not very object-oriented
	* Not very powerful (just simple dialog boxes)

| use                                      | description                                                                                                           |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `showMessageDialog(<parent>, <message>)` | Displays a message on a dialogue with an OK button                                                                    |
| `showConfirmDialog(<parent>, <message>)` | Displays a message and a list of choices (Yes, No, Cancel) and returns the user choice. (JOptionPane.YES_OPTION), etc |
| `showInputDialog(<parent>, <message>)`   | Displays a message and a text field for input; returns the user's value entered as a String.                          |
|                                          |                                                                                                                       |
Most of the parent parameters are null most of the time.

Note, only one popup will show up at once for JOptionPane. It pauses the program so no more will run until some sort of interaction.
```JAVA
import javax.swing.*;

public class MessageDialogExample {
	public static void main(String[] args) {
		JOptionPane.showMessageDialog(null, "How's the weather?");
		JOptionPane.showMessageDialog(null, "Second message");
	}
}
```

```JAVA
import javax.swing.*;

public class ConfirmDialogExample {
	public static void main(String[] args) {
		int choice = JOptionPane.showConfirmDialogue(null, "Erase your hard disk?");
		
		if (choice == JOptionPane.YES_OPTION) {
			JOptionPane.showMessageDialog(null, "Disk erased!");
		} else {
			JOptionPane.showMessageDialog(null, "Cancelled.");
		}
	}
}
```

```JAVA
import javax.swing.*;

public class InputDialogExample {
	public static void main(String[] args) {
		String name = JOptionPane.showInputDialog(null, "What's yer name, pardner?");
		JOptionPane.showMessageDialog(null, "Yeehaw, " + name);
	}
}
```

```JAVA
import javax.swing.*;

public class KnockKnockJoke {
	public static void main(String[] args) {
		int choice = JOptionPane.showConfirmDialog(null, "Will you please tell me a knock knock joke?");
		
		if (choice == JOptionPane.YES_OPTION) {
			String whoThere = JOptionPane.showInputDialog(null, "Who's there?");
			String moreWhoThere = JOptionPane.showInputDialog(null, whoThere + " who?");
			JOptionPane.showMessageDialog(null, "Oh ha ha ha ha, " + moreWhoThere + " You're SO funny!");
		} else {
			JOptionPane.showMessageDialog(null, "you're not very fun");
		}
	}
}
```

## Custom Graphical Input and Output
Option panes kinda suck. Make custom ones.

* **Frame**: A graphical window on the screen
* **Components**: GUI widgets such as buttons or text fields
* **Containers**: Logical groups of components
	* Think selecting an option from a series of buttons and if you select one all the other ones deselect

**JFrame** a Java frame. Example below:
```JAVA
import javax.swingx.*;

public class SimpleFrame {
	public static void main(String[] args) {
		JFrame frame = new JFrame();
		frame.setVisible(true);
	}
}
```

```JAVA
import java.awt.*;
import java.swing.*;

public class SimpleFrame2 {
	public static void main(String[] args) {
		JFrame frame = new JFrame();
		frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // x button actually closes it
		frame.setSize(new Dimension(300, 120));
		frame.setTitle("A frame");
		frame.setVisible(true);
	}
}
```

Constructor can accept a title but setTitle also exists.

| function                                    | description                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------------ |
| `JFrame frame = new JFrame(optional title)` | New object, constructor accepts frame title with a String                            |
| `setTitle(String text)`                     | Sets the title                                                                       |
| `setDefaultCloseOperation(int op)`          | Sets what happens when the x close button is clicked. Usually `JFrame.EXIT_ON_CLOSE` |
| `add(Component comp)`                       | Adds a component. Usually only add one, JFrames don't like multiple.                 |
| `setVisible(boolean)`                       | Makes it visible or non-visible.                                                     |
| `setSize(new Dimension(x, y))`              | Sets the size in pixels                                                              |
| `setIconImage()`                            | Sets the image in like the task bar to show what's running                           |
| `setLayout()`                               | How the frame should position its components                                         |
| `isResizable()`                             | Is it resizable?                                                                     |
| `setResizable()`                            | Sets is it resizable.                                                                                     |
Can also get the set methods

```JAVA
import java.awt.*;
import java.swing.*;

public class HuskerFanFrame {
	public static main(String[] args) {
		JFrame frame = new JFrame("Husker Fan");
		frame.setSize(new Dimension(500, 350));
		frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
		frame.setVisible(true);
	}
}
```

**COMPONENT PROPERTIES (UNIVERSAL)**

| name           | type                  | description                                                                                         | methods                |
| -------------- | --------------------- | --------------------------------------------------------------------------------------------------- | ---------------------- |
| background     | `Colors (Colors.WHITE)` | background color                                                                                    | `get/setBackground`    |
| enabled        | `boolean`             | whether the component can be interacted with                                                        | `is/setEnabled`        |
| font           | `Font`                | font used to display any text on the component (includes sizes, bold, italic. Not really font font) | `get/setFont  `        |
| foreground     | `Color`               | foreground color. Anything that appears in front of the background (generally text color)           | `get/setForeground`    |
| location       | `Point`               | (x,y) position of component on screen (very finicky almost never works)                             | `get/setLocation`      |
| size           | `Dimension`           | width, height of component (also finicky it probably wont work)                                     | `get/setSize`          |
| preferred size | `Dimension`           | width, height that the components WANTS to be (works better than size bc Java is temperamental)     | `get/setPreferredSize` |
| visible        | `boolean`             | whether the component can be seen on screen. True by default (frame is just weird)                  | `is/setVisible`                       |

### JTextField and JTextArea
A **Text Field** is like a label but the text can be edited and modified by the user. Commonly used for user input.

A text field is multiple line text field. The constructor accepts an integer for columns to know when to wrap the text. You also have to provide how many lines TALL you want it to be (int).
`JTextField textField = new JTextField(<lines>, <columns>)`

### Layout
A **Layout Manager** is an object contained inside frames and other graphical containers that decides the position and size of the components inside the container.
The default manager sizes each component added to occupy the full window space.

Change the layout by calling the `setLayout` method on the frame and passing a layout manager object.
	Next class.

For today, **FlowLayout**. It sizes each component to its preferred size and positions them in left-to-right rows.
It needs to be added right before the `setVisible(true)` line.
`frame.setLayout(new FlowLayout());`
