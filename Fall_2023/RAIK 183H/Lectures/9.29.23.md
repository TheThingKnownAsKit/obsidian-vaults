## 2D Arrays
Arrays are allowed to be *jagged*, which means you can have some rows/cols that are longer than the others.
```
[][][]
[][][][][][][]
[][][][]
  []
```

There is no way to reference a single column.

If you do `twoDArray.length` it'll print how many rows since that's technically x amount of arrays.
You have to specify `twoDArray[][].length` OR `twoDArray[].length` to get one row length.
	You can get the length of `twoDArray[rowNum].length` even if the values are all null, but if you try to do `twoDArray[rowNum][colNum].length()` it'll be a null pointer exception.
	Remember `.length` is for slots in arrays, and `.length()` is accessing the length of the data in the specified index. (Syntax error for ints or similar since they do not have a length)

You can give one [] a length and not the other
After, you have to do something like `arrayName[index] = new int[length];`
```
arrayName = {{row},
			 {row},
			 {row}};
```

*COMMON LOOP ERROR*
You need a nested for loop to loop through a 2D array. A common error is to use `j < arrayName[0].length` for the second for loop. Since arrays can be jagged, this can cause index out of bounds exceptions. Instead, do `j < arrayName[i].length`.
