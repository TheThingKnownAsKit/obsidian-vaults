## Functions I
A *structured algorithm* is an algorithm that splits a solution into coherent tasks.
	Task 1, task 2, task 3, maybe go back to task 1, etc.
	Put these in functions/methods

*Procedural decomposition*: dividing a problem into methods. A way to manage complexity

*Static method*: A named group of statements
	Denotes the structure, eliminates redundancy
	Like adding a new command to Java

Hover over function call and press ctrl to go to it instantly

Doesn't matter where you put the methods but it's good practice to put main at the bottom. Not always the case in other languages.
	Java is a compiled language, before the program runs it knows where everything is.
	Languages like Python are NOT compiled, it's interpreted, when it runs it's the first time it has run and the order DOES matter.
