## Finals and Magic Numbers
Use final keyword when creating variables you don't ever want to modify. Does not have to be initialized at the same time you declare it. But when you first assign it a value it cannot change.
Use final to avoid logic errors and it runs faster.

Use variables to make what you're doing clearer and also its adaptable to changes. Not just like 25 + 4 + 4, which is called a magic number (can also be a string its just an idea). Magic numbers are values that you insert as standalone ints/strings/whatever when they could be represented by a variable. Don’t do that.

Like if you tried double costOfGas = 2.799 * 18;

## Integer Division and Modulus
If you try to divide an int with another int and it does not mathematically result in a whole number, it will return the whole number only and disregard any decimals/fractions. It does not round up or down. This is called truncation.

The **modulus** of two numbers is the remainder of the division operation. The operation for this is %
27 / 5 = 5.4 5 rem 2
So int division = 27 / 5; //will result in 5

And int modDivision = 27 % 5 //will result in 2

Reads out loud as 27 mod 5

Can be used to find decimal values of numbers if that's all you want. It can calculate binary.

Note: Even if the variable you're doing the calculations on is a double, if you do not specify the number itself is a double, division will result in int division. So just do like 3.0 / 4.0 instead of 3 / 4

Int division is 3 / 4

Double division is 3.0 / 4.0, or cast it (when you need to cast a variable)

Casting a variable is treating it as a different data type. So you can treat an int like a double.

Note: You cannot downcast when attempting to perform an operation unless you specify you want to. So an int cannot have a value casted to a double in a equation. If you get a double value in the equation, you can cast the end result into an int to avoid an error in initializing the overall int.

## The Math Class

The math class is used to perform common math operations that operator symbols do not exist for.

It is called using Math.MethodName. You do not need to import it

Examples include:

Math.abs(value) for absolute value

Math.sin(value) for sine
