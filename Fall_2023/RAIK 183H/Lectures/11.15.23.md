* Bit (smallest unit possible)
	* 0 or 1
* Byte (smallest on modern computers)
	* 8 bits
	* Most computers actually use 32 or 64 as the absolute minimum bits (64-bit os)
* Numbers and instructions (depending on language) stored in 32 bits
	* Most common int size on a particular hardware is called a word

**Defragmentation** is when Java takes all the memory it has and consolidates small empty memory pockets into one big space. Eventually after objects get resized/removed/replaced, there will be small sections of memory everywhere that are too small to use. Java will get annoyed and defrag it.
OS also perform defrag on the entire computer's memory as a whole. A lot of the times memory for different programs is stored all over the place. This process tries to move it into more continuous blocks for faster processing.
