## Algorithms and Arrays
An *algorithm* is a set of steps that recognizes patterns to produce a certain result.
	Music taste in spotify

#### Examples of Algorithms
##### Min/Max
When finding a min/max element or similar, use the first index NOT zero.
	In other languages, they'd throw a fit over taking the value at array[0] without checking if the length of the array is greater than 0.

##### Swapping
When swapping values in an array, you need a temp variable otherwise they'll both end up equaling the same thing.

##### Reversing
When reversing the order of an array, loop through for .length / 2 - 1times. The value on the left is just array[i ], and the value on the right is array[array.length - 1 - i] (remember length is one more than indexes). Use temp values. Or just create a new array for the sorted values.
```
int[] height = {2, 3, 5, 5, 15}
for (int i = 0; i < (height.length / 2); i++) {
	int temp = height[i];
	h[i] = h[height.length - 1 - i];
	h[height.length - 1 - i] = temp;
}
```

##### Tallying
Finding the digit that occurs most frequently in an array or int
	If it's an int, first you have to make an array of all the digits. Use the same math we've been using forever to find each individual digit.
	If it's an array, you can skip the while loop.
```
// assume n = 669260267
int[] counts = new int[10];
int bestIndex = 0;
while (n > 0) {
	// pluck off a digit and add to the proper counter
	int digit = n % 10;
	counts[digit]++;
	if (counts[digit] > counts[bestIndex]) {
		bestIndex = digit;
	}
	n = n / 10;
}

// Optional separate loop
for (int i = 0; i < counts.length; i++) {
	if (counts[digit] > counts[bestIndex]) {
		bestIndex = digit;
	}
}
```
Note: You could put the if statement in an for loop for the length of counts. This is less efficient if n is 10 or less since it'll do MORE comparisons. If n is greater than 10, it is more efficient to put them in separate loops since that will result in LESS comparisons.
	Remember counts is just an array of how many times a digit (corresponding to the index) occurs. If 6 appears 4 times, then the index at counts[6] will equal 4. It will never be bigger than 10 because there's only 0-9 digits. The while loop goes through EVERY digit, not just for how many digits exist.
