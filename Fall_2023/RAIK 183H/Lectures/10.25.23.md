A constructor can call another constructor by doing `this(parameters)`.
Have the default constructor do this and use default values for parameters. This is because when programs get bigger it can be tedious and resource intensive to manually set default values.

Static methods CANNOT reference non-static variables.
Static means it will be the same through all objects. If the thing can be different from object to object, it cannot be static.
Non-static if it requires state data.
Cannot directly reference non-static methods in a static method. Create a new object and then call those methods on the object.

*Module:* A reusable piece of software, stored as a class. Includes related behaviors but no state. Full of static methods. Partial program, no main method.
	The InputValidation class. Also things like Math, Arrays, System. Libraries. Tools.
