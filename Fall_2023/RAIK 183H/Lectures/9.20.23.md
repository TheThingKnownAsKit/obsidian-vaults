## Scope
*scope*: The portion of a program where a given variable exists. It is from its declaration to the end of the block ( pair of {} braces) in which it was declared.
	Includes loops, if/else if/else, methods, classes, etc.
		If declared in a loop statements/initialization, it exists until the end of that for loop and persists its value between iterations.
		If a variable is declared in an if statement/switch statement/while loop it will exist until the end of that structure and will lose its value at the close of the structure/case

You can use a block for no reason (like no if statement or loop) but it isn't common. Usually if you have a really long main method and need to save memory since anything in a block after its finished running gets deleted.
```
main {
Statement
	{ // Nothing this is for no reason but you can do it
		Statement
	}
}
```
## Enumerated Types
*enum*: A type of objects with a fixed set of constant values.
	C has enums that are really ints; Java's are immutable objects (reference type not primitive).
	Use enums instead of int or string constants when there is a reasonable and finite number of options.
		Enums are more readable, safer, and more powerful.
```
public enum Name {
	VALUE, VALUE ..., VALUE
}
```
Examples:
```
public enum Suit {
	CLUBS, DIAMONDS, HEARTS,SPADES
}
```
```
public enum DaysOfWeek {
	SUNDAY, MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY
}
```
Note: For days of week, you can declare them in any order, BUT you can also compare them based on logcal order. So if you wanted to know if sunday is greater than thursday, you need to declare them in order.
	The values are stored kinda like integers. Sunday is stored as 0, monday as 1, etc.

Typically there is a separate very short file containing all your enums (and maybe constants?).
	By short I mean the example code above would be the whole file, just those three lines and you can use them forever.

#### Things you can do with enums
Use it as the type of a variable, field, parameter, or return
`Suit suit = Suit.HEARTS;`

Compare them with ==
`if (suit == Suit.CLUBS) { .... }`

Compare them with `compareTo` (by order of declaration)
`int diff = suit.compareTo(otherSuit);`
	Returns 0 if equal and -num if suit is less than otherSuit and +num if greater than otherSuit.
		The num can be any -+, like -5 if it is five back in the list so usually just use its sign. This value can be significant but it is usually difficult to impossible to use that information functionally.

Print them
`System.out.println(suit); // Prints "HEARTS"`

Use them in a switch statement
```
switch (suit) {
	case Suit.HEARTS:
		some_code;
		break;
	case Suit.DIAMONDS:
		some_other_code;
		break;
	default:
		still_other_code;
}
```

#### Enum Methods
| method              | description                                                                              |     |     |
| ------------------- | ---------------------------------------------------------------------------------------- | --- | --- |
| int compareTo(E)    | all enum types are Comparable by order of declaration                                    |     |     |
| boolean equals(o)   | not needed; can just use ==                                                              |     |     |
| String toString()   | String value of the enum (defaults to name)                                              |     |     |
| int ordinal()       | returns an enum's 0-based number by order of declaration(first is 0, then 1, then 2, ..) |     |     |
| static E valueOf(s) | converts a string into an enum value                                                     |     |     |
| static E[] values() | an array for all values of your enumeration                                              |     |     |                    |                                                                                          |     |     |

Example:
```
String x = "FRIDAY"
dayOfWeek xDay = DayOfWeek.valueOf(x);
```
