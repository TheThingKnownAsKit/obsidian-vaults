## Objects
Default access status is package private. Public is accessible anywhere. Private is only in the class.
Variables in objects are almost always private. Use methods to return those variables.

Object classes cannot be static. **Static** means it cannot have states outside of itself. There's only one copy of it that exists and only one copy that runs.

Make objects in non-static classes and give it properties and abilities if applicable.
Create new objects in the actual logic methods, use the syntax
`ObjectName varName = new ObjectName();`
`Town kauffman = new Town();`
The **class** is Town in this case. The **object** is kauffman. The class defines characteristics and behavior, and the object is created with the new keyword.
The thing called after the new keyword is called the **constructor**. You can pass arguments to it instead of having to individually assign characteristics. You can have more than one if there's multiple options of parameters you can pass.
**Getter** methods retrieve information and return it if they have access to it.
**Setter** methods set the state of an object. Getters and setters go in pairs.
**IMPORTANT, IF YOU RIGHT CLICK ON A VARIABLE AND GO TO SOURCE, THERES AN OPTION TO AUTO MAKE GETTERS AND SETTERS AND IT'LL EVEN MAKE THE JAVADOC COMMENT**

Use the keyword **this** to specify that this thing is about this specific class. Useful when you have a local variable with the same name as a class variable. It is standard to use the same name in the constructor as the field variables.
	Works on variables and methods.

**Encapsulation** is the process of capturing all the specific information about an object. This includes ownership of the data. 

#### Class Essentials
```
public class Town() {
	//Field variables
	private String name;
	private String mayor;
	private double xCoord;
	private double yCoord;
	
	//Constructor
	public Town(String name, String mayor, double xCoord, double yCoord) {
		this.name = name;
		this.mayor = mayor;
		this.xCoord = xCoord;
		this.yCoord = yCoord;
	}
	
	//Getter
	public String getMayor() {
		return this.mayor;
	}
	
	//Setter
	public void String setMayor(String mayor) {
		//You can also put conditions in here to control who and what conditions can change the mayor.
		
		this.mayor = mayor;
	}
	
	//Overrides built-in toString() method
	public String toString() {
		return "";
	}
}
```

The class variables go at the top.
The constructor is second after the variables.
toString() is the last method (unless there's a main which is unlikely).
