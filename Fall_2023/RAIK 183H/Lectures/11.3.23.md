## File Output
**PrintWriter**: An object in the java.io package that lets you print output to a destination such as a file.
* Any methods that work on System.out will work on a PrintWriter (print, println, printf)
`PrintWriter writer = new PrintWriter(new File("file name"));`

```
PrintWriter output = new PrintWriter(new File("out.text"));
output.println("Hello, file!");
output.println("This is a second line of output.");

output.close();
```

This will make a new file. (you might have to refresh the folder for it to show up in package explorer)
If it's run again on a file with the same name, it'll **truncate** it. Empty the file and then refill it.
