## Primitive Data Types

Built in, very simple, stored exactly how it is, straightforward, exactly what it says it is

| Data Types | Size (Bytes)    | Range                                                        |
| ---------- | --------------- | ------------------------------------------------------------ |
| byte       | 1 byte (8 bits) | -128 to 127                                                  |
| char       | 2               | 0 to 65,535                                                  |
| Short      | 2               | -32,768 to 32,767                                            |
| int        | 4               | -2,147,483,648 to 2,147,483,647                              |
| long       | 8               | -9,223,372,036,854,775,808 to  <br>9,223,372,036,854,775,807 |

| double     | 8               | 4.9e^-324 to 1.8e^+308                                       |

The positive range is always one less than the negative because it matters more about how many discreet  identities something can have, and 0 counts as one. So it takes up the 128th slot because 0 cannot be negative. Also bitmath which we will learn next week.

Char, pronounced char as in charcoal. The range is numbers, not characters. According to the ASCII table, every number cooresponds to a certain letter or special text (like start of heading, start of text, backspace, horizontal tab, /, etc). The number translates to a character when it prints. You represent chars with single quotes ''

Floats are bad because they only show a max of 16 digits after a decimal. Really inaccurate, it's bad. Use doubles. Even doubles cut off somewhere in significant digits, so really really precise things (like money) are generally converted into ints.

## Scanner
Steps to use a scanner:
Import the scanner at the top with: import java.util.Scanner;
Declare and initialize a scanner variable with: Scanner scnr = new Scanner(System.in);
You can set a variable equal to user input with: variableName = scnr.nextInt(); (or like double or char or string(just next or nextLine for string))
If you haven't declared the variable beforehand then make sure to add the data type before variableName

REMEMBER TO CLOSE THE SCANNER WITH: scnr.close();

Print statements follow order of operations. Strings are greater than addition, so if a string comes before any addition in a print statement then the whole addition will be treated as a string. Will not happen if it comes after addition.

Also, multiplication is greater than strings, so even if string is before multiplication, it will still end up multiplying.
