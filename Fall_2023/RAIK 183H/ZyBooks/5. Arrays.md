## 5.1 Array concept (general)
An *array* is a special variable having one name but storing a list of data items, with each item being directly accessible. (also called a vector). An array can be ordered.
Each item in an array is known as an *element*. Each element's location number is called the *index*.
Accessed by `myArray[2]` is the index at 2. In Java, indexes start at 0. If no value is given to an index, it's default value is 0 (or false if boolean).
Declared with `dataType[] arrayName = new dataType[numElements];`
					  `int[] gameScores = new int[4];` Or you can just do `int[] gameScores;` without initializing it.
					  Or, if you want to initialize an array with non-default values, you can do `int[] myArray = {5, 7, 11};`. You do not need to use the new keyword.

Note: It is usually necessary to use an if statement when accessing elements using user input (until we learn try catch) because if the user inputted number is outside the array range, it'll cause a runtime error.
NOTE: For loops are your best friend for arrays. Use i to access indexes and the array's length as the conditional.
	Evaluates the number of elements, not the last index.
	Start your i at 0 because the indexes are N - 1 and not N.

## 5.9 Two-dimensional arrays
An array can be declared with two dimensions. `int[][] myArray = new int[R][C]` represents a table of int variables with R rows and C columns, so R * C total.
To initialize during declaration, do:
```
int[][] rowCol = {{col1, col2, col3}, {col1, col2, col3}}
```
	Each sub {} is a row.
Note: When for looping through an array, use two for loops that iterate over i and j.

## 5.10 Enhanced for loop: Arrays
The *enhanced for loop* is a for loop that iterates through each element in an array. Also known as a *for each loop*.
It declares a new *loop variable* whose scope is limited to the for loop, that will be assigned with each successive element of an array. It only allows elements to be accessed forward from the first element to the last.
```
for (type loopVariable : array) {
	Code
}
```

A *common error* is modifying the loop variable in an attempt to modify the array's elements. The loop variable is a copy of the current element, so modifying it is only modifying the copy and not the actual array value.
