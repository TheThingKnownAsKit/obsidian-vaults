	12## 11.1 Objects: Introduction
An *object* is a grouping of data (variables) and operations that can be performed on that data (methods).

*Abstraction* means to have a user interact with an item at a high-level, with lower-level internal details hidden from the user (aka *information hiding* or *encapsulation*).
An *abstract data type (ADT)* is a data type whose creation and update are constrained to specific well-defined operations. (getters and setters I think)

## 11.2 Using a class
The *class* construct defines a new type that can group data and methods to form an object. A class's *public member methods* indicate all the operations a class user can perform on the object.

A *reference variable* can refer to an instance of a class. The `new` operator explicitly allocates an object of the specified class type.
`Restaurant favLunchPlace = new Restaurant()`
The `.` operator, the *member access operator*, is used to invoke a method on an object.

## 11.4 Mutators, accessors, and private helpers
A class's public methods are commonly classified as either mutators or accessors.
	A *mutator* method may modify ("mutate") a class's fields. *Setter*
	An *accessor* method accesses fields but may not modify a class's fields. *Getter*
Note: Some mutators and accessors aren't associated with just one field, such as print() methods.

*Private helper methods* help public methods carry out tasks.

## 11.5 Initialization and constructors
It's good practice to initialize all variables when declared, even if it's to 0 or "NoName" or something. Do this in a constructor. If the constructor does not have any parameters, use the defaultish values above.
Just use `this(parameters);` instead.
#GoodPractices 

A *constructor* is called when an object of that class type is created and can be used to initialize all fields. It has the same name as the class and returns no type, not even void.
If none is defined, the compiler will implicitly define one with no parameters.
`public <ClassNameHere>() {....}`

## 11.6 Constructor overloading
You can *overload* constructors by defining multiple constructors differing in parameter types. When creating a new object, it will use the constructor with corresponding parameter types.

If any constructor is explicitly defined, the compiler will not implicitly define a default constructor. It is good practice to also explicitly define a default constructor.

## 11.9 Unit testing (methods)
*Unit testing* is the process of individually testing a small part or unit of a program, typically a method.
A unit test is typically conducted by creating a *testbench*, or test harness, which is a separate program whose sole purpose is to check that a method returns correct output values for a variety of input values.
Each unique set of input values is known as a *test vector*.
![[Pasted image 20231008122528.png]]

A better test harness would only print a message for incorrect output. Java provides a compact way to print an error message when an expression evaluates to false. **Assert** is an operator that prints an error messages and exits the program if the provided test expression evaluates to false, having the form:
`assert testExpression : detailedMessage;`
A completed message includes the current line number and a detailed message denoted by detailedMessage, which is typically a String literal or similar.
![[Pasted image 20231008122843.png]]

NOTE: **Assertions are not enabled by default**. Programmers must execute Java programs with additional command-line options in order to enable, Specifically, the command-line option -ea is necessary at run-time. `java -ea HrMinToMinTestHarness`

Good test vectors also include *border cases* that represent fringe scenarios. (tiny numbers or huge numbers, negative numbers, etc). Extreme or 'weird' inputs.

## 11.20 Static fields and methods
The keyword *static* indicates a variable is allocated in memory only once during a program's execution. They reside in the program's static memory region and have a global scope.

In a class, a *static field* (also called class variables) is a field of the class isntead of a field of each class object. This, they are independent of any class object, and can be accessed without creating a class object.
	Created and initialized in the class definition.
	Within a class method, it is accessed using the field name.
	A public static field can be accessed outside the class using dot notation: `ClassName.fieldName`
Non-static fields are called *instance variables*.
#Methods #Classes #Objects 

A *static member method* is a class method that is independent of class objects. Typically used to access and mutate private static fields.
Since they are independent of class objects, the `this` parameter is not passed to a static member method. So, a static member method can only access a class's static fields.
