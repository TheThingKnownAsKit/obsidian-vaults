A <mark style="background: #ADCCFFA6;">goal</mark> describes the intention of one or more stakeholders with regard to the objectives, properties, or use of the system

<mark style="background: #ADCCFFA6;">AND-Decomposition</mark> is when you decompose a super-goal of G into a set of sub-goals, $G_{1},\dots,G_{n}$ with $n\geq_{2}$ AND <mark style="background: #BBFABBA6;">all sub-goals must be satisfied in order to satisfy the super-goal G</mark>

<mark style="background: #ADCCFFA6;">OR-Decomposition</mark> is when you decompose a super-goal of G into a set of sub-goals $G_{1},\dots,G_{n}$ with $n\geq 2$ AND <mark style="background: #BBFABBA6;">only one of the sub-goals needs to be satisfied to satisfy the super-goal G</mark>

AND/OR goals can be combined into an <mark style="background: #ADCCFFA6;">AND/OR Goal Tree</mark> where nodes represent goals and directed edges represent AND-decomposition and OR-decomposition relationships between goals
- Each node is related to exactly one super-goal aka it can only have one incoming edge
- No cyclic paths allowed
- Goals are usually given short labels with annotations if necessary

In practice, AND/OR goal trees are often too restrictive, so you use sub-goals in an AND/OR Goal Graph. An <mark style="background: #ADCCFFA6;">AND/OR Goal Graph</mark> is a directed, acyclic graph with nodes representing goals and edges representing AND/OR Decomposition relationships
- A node can have more than one incoming edge
- AND/OR graphs are acyclic

<mark style="background: #BBFABBA6;">There are seven rules for textual goal documentation.</mark> They are the following:
1. Document goals concisely 
2. Use active voice
3. Document the intention precisely
4. Decompose high-level goals
5. Document the added value
6. Document the reasons for introducing a goal
7. Avoid defining unnecessary restrictions

An <mark style="background: #ADCCFFA6;">Achieve Goal</mark> is a goal that defines GIVEN, WHEN, and THEN. It prescribes intended behaviors where a target condition must sooner or later hold whenever some other condition holds in the current system state
