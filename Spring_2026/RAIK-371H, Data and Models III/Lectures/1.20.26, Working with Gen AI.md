Generation step uses context to predict next token -> next token prediction layer uses a softmax function to normalize all possible options into a prob. distribution -> select based on distribution -> select based on greedy, random, top-k, or top-p

<mark style="background: #ADCCFFA6;">Greedy sampling</mark> selects the single most likely token next. Prone to getting caught in cycles of the same words
<mark style="background: #ADCCFFA6;">Random sampling</mark> uses the output values as a probability distribution and picks one with weighted sampling
<mark style="background: #ADCCFFA6;">Top-K</mark> is random sampling but restricted to the top k results
<mark style="background: #ADCCFFA6;">Top-P</mark> is random sampling but restricted to the top results who's cumulative probability is p
