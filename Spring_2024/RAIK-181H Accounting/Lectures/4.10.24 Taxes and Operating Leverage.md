# TAXES
$\frac{ProfitAfterTaxes}{1-TaxRate}=ProfitBeforeTaxes$

If net income is 100,000 and tax rate is 21%, what is profit before taxes?
$\frac{100000}{1-0.21}=126583$
You can use this number when determining sales volume

## Example
$\frac{63000}{1-0.3}=90,000$

Sales volume in units  = $\frac{FC+ProfitBeforeTaxes}{CM/Unit}$

CM = $240,000-160,000=80,000$
CM/Unit = $80,000/400=200$
To find CM/Unit you could also just do 600-400 = 200

Sales volume = $\frac{50000+90000}{200}=700$
Need to sell 700 units, which at a price of 600 per set is 420,000

To find actual profit, factor in costs

| Thing               | Number               |
| ------------------- | -------------------- |
| Sales               | 420,000              |
| Less VC             | 700x400<br>= 280,000 |
| CM                  | 140,000              |
| Less FC             | 50,000               |
| Income before taxes | 90,000               |
| Tax                 | 30%                  |
| NI                  | 63,000               |

## Target Revenue Increases
NOTE: Variable costs do not give operating leverage because those costs change in proportion to change in level of sales.

A **SHORTCUT** you can do is take operating leverage x sales increase percentage and it will tell you how much net income will increase as a percentage
Using the example a/b above, 
	$17*0.05=85\%$ if we want to increase revenue % by 5%
	$17*-0.08=-136\%$ reduction if revenue decreases by 8%
