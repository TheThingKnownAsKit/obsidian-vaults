Opposite of product rule

2. factor the denominator into powers of linear functions (ax+b)^k and irreducible quadratics

Example:
Find $\int \frac{x}{x^2-5x-6}dx$

Here $x^2-5x-6=(x-6)(x+1)$
$\frac{x}{(x-6)(x+1)}=\frac{A}{x-6}+\frac{B}{x+1}$ A and B are unknowns
$=\frac{A(x+1)+B(x-6)}{(x-6)(x+1)}$ found a common denominator and combined fractions

So we need x = A(x+1)+B(x-6) for all choices of x
So if x = -1 then,
	-1 = A(-1+1)+B(-1-6) -> -1=-7B so B = 1/7
	6 = A(6+1)+B(6-6) -> 6 = A7 so A = 6/7

$\int\frac{x}{(x-6)(x+1)}dx=\int\frac{\frac{6}{7}}{(x-6)}dx+\int\frac{\frac{1}{7}}{(x+1)}dx$
$=\frac{6}{7}\ln|x-6|+\frac{1}{7}\ln|x+1|+C$
