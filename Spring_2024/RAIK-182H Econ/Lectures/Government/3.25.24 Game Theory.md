The **best response** is the most optimal strategy taking my opponent's as given
If the opponent plays black, the best response is to play red, as seen by:

|       | B     |
| ----- | ----- |
| **B** | 3   3 |
| **R** | 5   0 |

If the opponent plays red, the best response is to play red, as seen by:

|       | R     |
| ----- | ----- |
| **B** | 0   5 |
| **R** | 2   2 |

Because the best response is to always play red, this is the **dominant strategy**.
You can do this same analysis with the opponent and it will also result in always playing red because we play under the same rules (in this case). Because of this, it achieves a **dominant strategy equilibrium** where no one wants to deviate from their strategy

The game we played in class is a version of the **prisoner's dilemma**. Everyone would be better off if the players agreed to play black, but because you get nothing if the other person decides to play red and they get more so there's incentive, it is safer to just play red.

Game without a dominant strategy: consider citizens of a dictatorship deciding whether to protest

|       | N                                 | Y                                   |
| ----- | --------------------------------- | ----------------------------------- |
| **N** | You: No change<br>Them: No change | You: Stay home<br>Them: Arrested    |
| **Y** | You: Arrested<br>Them: Stay home  | You: Revolution<br>Them: Revolution |
This is a **coordination game**: both players are better off if they can coordinate their choices
In this situation, look for a **Nash equilibrium** in which a combination of strategies in which each is a best response to the strategies of others. Put differently, no one wishes they could change their mind after the dust has settled

This is an **anti-coordination game** where players prefer to adopt opposite but complementary strategies
