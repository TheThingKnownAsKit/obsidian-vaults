# ITERATOR
```Java
ArrayList<String> profs = new ArrayList<String>();

for (String p: profs) {
	System.out.println(p);
}

// better. p gets updated with next item, loops until null
for (Iterator p = profs.iterator(); p.hasNext(); ) {
	System.out.println(p.next());
}

// While loop version
Iterator<String> p = profs.iterator();
while (p.hasNext()) {
	System.out.println(p.next());
}
```

An **iterator** is an object that can be "looped through". Makes your object loopable by implementing the Iterable interface
`interator()` which returns an `iterator<T>` object
Just for collections

# MAPS
Technically not a Collection but similar
Also known as dictionary in other languages

Map holds key-value pairs:
* **Key**: unique identifier
	* Must be able to test for equality with other keys (commonly String and Integers)
* **Value**: an object associated with that identifier
* Keys and values usually have different data types

A **HashMap<K, V>** does not care about ordering and is faster. Need to define equals and hashCode for all your keys
	**LinkedHashMap** also exists
A **TreeMap<K, V>** guarantees orders the pairs (smallest to largest) . Slower to change easier to search. Define equals and implement the Comparable interface for all the keys

Good practice to declare them as general Maps then get specific with the constructor

The way a HashMap works is it creates an array of LinkedLists. The ordering is functionally random but it is determined by weird math the HashMap does. Basically, there is a defined order but you will have no idea what this order is
