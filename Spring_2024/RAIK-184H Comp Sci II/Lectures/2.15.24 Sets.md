# SETS
A **Set** is a Collection with no repeated elements (the equals() method is used to determine this)

There is one important function in Collection relevant to sets. `retainAll(Collection c)` keeps in this collection only those items that are also included in c

Sets can be implemented with:
* `HashSet<T?` is the best for most purposes, uses hashing to go fast
* `TreeSet<T>` guarantees an iterator will return elements in a sorted order
* `LinkedHashSet<T>` guarantees iterators will return in insertion order
