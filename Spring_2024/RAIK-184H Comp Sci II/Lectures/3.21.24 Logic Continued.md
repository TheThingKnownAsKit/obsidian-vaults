# ORDER OF OPERATIONS

|         | Math        | Java     |
| ------- | ----------- | -------- |
| and     | p $\land$ q | p && q   |
| or      | $\lor$      | p \|\| q |
| xor     | $\oplus$    | p ^ q    |
| not     | $\lnot$     | !p       |
| if/then | $\implies$  |          |
| iff     | $\iff$      |          |

| Operator | Precedence |
| -------- | ---------- |
| not      | 1          |
| and      | 2          |
| or       | 3          |
| xor      | 4          |
| if/then  | 5          |
| iff      | 6          |
Parenthesis take first
Evaluates rightmost first if there's a tie 

Examples:
$p\implies q\implies r$ will execute like $(p\implies(q\implies r))$
$p\implies q \iff r$ will execute like $(p\implies (q\iff r))$

# IMPLIES DETAILS

*The arrow only points one way for a reason*. p MUST imply q but q does not imply p. p can also be true if q is wrong because you can do it anyways. Therefore, it is only false if p is true and q is not what was implied
False in the first variable will always result in true
![[Pasted image 20240317191538.png]]

Remember implies does not mean causality, only expected correlation. p did not cause q

(a $\implies$ b $\implies$ c $\implies$ d $\implies$ e $\implies$ f $\implies$ g $\implies$ h $\implies$ i $\implies$ j)

In this, if j is false and everything before it is true, it will ALWAYS remain false. This is the only case where the result will be false as the other cases will be flipped by other values being false
There is only ever one case where the statement is false
(results may vary if there are 3 or less variables)

# EQUIVALENCE
One way to test for equivalence is making a truth table for both propositions (the resulting value) and every row must be equal

| p   | q   | p implies q | not p | (p implies q) and not p |
| --- | --- | ----------- | ----- | ----------------------- |
| T   | T   | T           | F     | F                       |
| T   | F   | F           | F     | F                       |
| F   | T   | T           | T     | T                       |
| F   | F   | T           | T     | T                       |
So (p implies q) and not p is equivalent to not p

| p   | q   | not q | not p | p implies q | not p or q |
| --- | --- | ----- | ----- | ----------- | ---------- |
| T   | T   | F     | F     | T           | T          |
| T   | F   | T     | F     | F           | F          |
| F   | T   | F     | T     | T           | T          |
| F   | F   | T     | T     | T           | T          |
p implies q is equivalent to not p or q

# LAWS OF PROPOSITIONAL LOGIC
![[Pasted image 20240321115911.png]]

Associative laws: basically if you have a series of ONLY ands or ONLY ors then you can evaluate them in any order and it doesn't matter

De Morgan's Laws: Remember to negate the sign as well as the variables

Absorption Laws: If you repeat two variables mixed with an OR, the other variable doesn't matter and it simplifies to the repeated one. The OR can be inside or outside the parenthesis it doesn't matter
