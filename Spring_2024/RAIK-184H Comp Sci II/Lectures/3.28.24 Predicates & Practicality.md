**Predicates** can be thought of as any function that accepts at least one argument and returns a boolean value

Kind of like a for each loop with the :
collection : assertion
loop : check iteration
for each thing in collection : does it satisfy this condition

Proof strategies:
* For all statements
	* To prove it: direct proof with mathematical induction
	* To disprove it: provide a single counter example
* For some statements:
	* Finish

To negate a predicate, switch every quantifier. All's become some (upside down A's and backwards E's), some become all's. Also negate the right side
$\forall\to\exists$, and $\exists\to\forall$, then $\lnot$right side
	For example, $\exists s\forall p : Love(p,s)\to\forall s\exists p : \lnot Love(p, s)$
	Goes from there exists someone who all people love -> for all people there exists one person that they do not love
