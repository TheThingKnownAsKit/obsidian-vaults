Deletion
By cases:
1. node has no children - search until you find the target, then delete it from the parents child list
2. node has one child - make the search's parent adopts the search's child
3. node has two children - find the smallest one in the same subtree tree or the biggest one in the other subtree tree. This forces case 1 or 2. Then copy the value into the original node. Now delete the 19 using case 1 or 2
