```Java
frogs (int n) {
	if (n <= 0) {
		return n;
	} else {
		return frogs(n / 2 + 2) + 1;
	}
}
```
Doesn't work because it reaches equilibrium. Gets stuck at a value

```Java
public static int numMonthsToPayOffDebt(double debt, int payment) {
	if (debt <= 0) {
		return 0;
	} else {
		return 1 + numMonthsToPayOffDebt((debt * 1.02) - payment, payment);
	}
}
```
