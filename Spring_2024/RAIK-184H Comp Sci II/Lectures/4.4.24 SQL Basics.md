SQL (Structured Query Language) and Sequel are basically the same thing. SQL a language with many dialects. It's parts are:
* **DDL** - Data Definition Language. Allows you to define, delete, and modify relation schemas (similar to declaring variables in a class)
	* Usually used for creating data
* **DML** - Data Manipulation Language. Allows you to insert, delete, modify tuples (ordered pair) in database
	* Usually used for dealing with data

In this class, we are talking about "MySQL" language specifically.
SQL is the language, MySQL is our environment

# CREATING A DATABASE
`CREATE DATABASE database_name;` literally the whole command. There are a lot of arguments that *can* go along with this command but they are dialogue specific

Some databases provide GUI interfaces to do this but the command is the most common

To create a table,
```MySQL
CREATE TABLE table_name
(
 column_name     datatype[size],
 column_name     datatype[size]
);
```
Not case sensitive somehow. The capital syntax indicates what is a command and what is a name but it is not required. Do not always need to give size
```MySQL
CREATE TABLE books
(
 ISBN        char[20],
 title       char[50],
 authorID    int(11),
 price       float
);
```

`UNIQUE` Any data entered that duplicates the data in these columns is rejected
```MySQL
(
studio_id    Number,
name         varchar(20),
city         varchar(50),
state        char(2),
UNIQUE       (city),
);
```

A **primary key** is a single field or combination of fields that uniquely defines a record. Do this with `PRIMARY KEY` clause
```MySQL
(
studio_id    Number,
name         varchar(20),
city         varchar(50),
state        char(2),
PRIMARY KEY  (studio_id),
);
```

NOT NULL is a clause used to prevent null values, just add it to the end of the datatype


Example:

# DATA

Possible data: String data, numeric data, temporal data (time), large objects (images, graphs, lots of text)

## String Data
Strings can be:
* Fixed Length Strings - Occupy the same length of space in memory no matter how much data is stored in them.
	* Fast, will not trim to size, cannot get any larger
	* `CHAR(n)` where n is the length of the String
* Variable Length String - Specified with maximum length possible but will use the size of the data actually stored
	* Slow, will trim to size, cannot get any larger than the maximum
	* `VARCHAR(n)` where n is the maximum length of data possible for the type

## Numerical Data
All numerical data is stored as strings and not bytes, hence why all the sizes are in digits. Sometimes called different things and these are only the most common ones

`DECIMAL(size1, size2)` floating point number with the first size being the total number of digits allowed and size2 being the digits allowed after the decimal point (precision)
	Note, size1 INCLUDES size2

`INT(size)` where size is the total number of digits

`TINYINT(size)` integer between 0 and 255. Actually stored as bytes. Size is optional you don't need to include it
	There are no booleans in this language so TINYINT's with size 1 are used to store 0 or 1 for yes/no

## Temporal Data
Also stored as strings

* DATE
	* YYYY-MM-DD (the order makes it easier to sort because you'd want to sort in yeare, month, day order)
* TIME
	* Military time (0-24). Follows HH:MM:SS with 0's padded if needed
* DATETIME
	* Date and time combined so YYYY-MM-DD HH:MM:SS
	* "2018-03-15 21:30:00"

TIMESTAMP uses the number of milliseconds since some random day in 1960

## Large Data Objects
Large paragraphs of text, images, files

Character Large Objects (CLOBs) are human readable text - parsable 
Binary Large Objects (BLOBs) are things stored in binary, usually images


## Retrieving
Use the SELECT statement to pull information from the table

```MySQL
SELECT what_to_select FROM which_table WHERE conditions_to_satisfy;
```

The simplest returns EVERYTHING from the table, which is just `SELECT * FROM pet;`

If you want all the columns but just particular rows, you can do `SELECT * FROM pet WHERE name = "Bowser";`. Conditions can also work like `SELECT * FROM pet WHERE birth >= "2018";`
You can combine conditions with AND

You can ask for specific columns by separating the conditions with ,
`SELECT name, owner FROM pet;` or just name
Combining this with condition can let you get rows with specific conditions

`SELECT DISTINCT owner FROM pet;` DISTINCT means it will only return unique values, it removes all duplicates. This would get all owners who own at least one pet

You can add order by at the end to return the data in a specific sorting. Like order by species would be alphabetical species

`SELECT owner FROM pet WHERE name = "Bowser";` finds the owners of the pets named Bowser
`SELECT * FROM pet WHERE species = "turtle" AND birth < "2017";` selects all pets who are turtles and were born before 2017. If you used LIKE instead of = then turtle would not be case sensitive
`SELECT DISTINCT species FROM pet;` selects the species of pets represented in the database with no duplicates

Use ORDER BY to sort things. Use DESC to do descending. You can't sort unless the thing is in select
