**Discrete math** is the branch of math that cs is built on. Discrete math is the difference between doing math with integers and with decimals. It does not use decimals or ambiguity. There is always a distinct, discrete answer with no middle ground. It is 1 or 0 not 0.5

# FUNCTIONS
For every input, there is one output. Outputs can overlap but the same input cannot give different, multiple, or no answers. Functions are defined from x-->y, not the other way around
Vertical line test my best friend
	Horizontal if flipped to y (idk why you'd do this but you can)

A **function** f:$X\to Y$ maps any element of X to element of Y. Every element of x is mapped to just one value in y, it is ALWAYS defined discretely

f is **injective** (one-to-one) if no two elements in X are mapped to the same value
	$|X| \le |Y|$ because there is at LEAST one y for every x but there could be y's that are unmapped
f is **surjective** (onto) if for all y's in Y (the set of y) there exists an x in set X such that f(x) = y. For every y, there is an x that maps to it
	$\forall y\epsilon Y\exists x\epsilon X$ s.t. f(x) = y
	Discrete math form of saying the defining sentence (what if I cried)
		Upside down A = for all
		Epsilon = in
		Uppercase letters are the Set Y and X
		Reverse E means exists
	$|X|\ge|Y|$ because there is at LEAST one x for every y but there could be multiple x's that map to the same y

f is **bijective** if it is both injective and surjective. There is always an inverse (you could take the y and find the x)
	$|X| = |Y|$
	The size of set X is the same as set Y

# COMPOSITION
The exact same as normal math composite functions. Evaluate the innermost function at the value of x and then use the resulting value to evaluate the next function. So on and so forth
$f\circ g(x) = f(g(x))$

Remember $\lceil x \rceil$ means ceiling (round up to the whole number, even if it's just 0.1 it is now 1)
$\lfloor x \rfloor$ means floor it (round down)

To find the **inverse** of a function, you solve for the opposite variable
	Usually x
	The inverse of $y=2x+5$ is $x=\frac{y-5}{2}$
	Denoted as $f^{-1}(y)$
