Propositions should always be positive when made. If you want a negative sentence just use not
	Do not use "I will not run"
	Do $\lnot$"I will run"

**When setting up a all possible variable values for a truth table:**
Where n is the number of variables
First variable always has $2^{n-1}$ trues followed by $2^{n-1}$ falses -> half true then half false
Second variable alternatives between $2^{n-2}$ trues and $2^{n-2}$ falses
Third variable alternatives between $2^{n-3}$ trues and $2^{n-3}$ falses
