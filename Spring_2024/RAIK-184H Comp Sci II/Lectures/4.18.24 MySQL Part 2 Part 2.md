# QUERYING MULTI-TABLE DATA
To query data using foreign key relationships, you must use a JOIN clause
Kinds of joins:
* <mark style="background: #ADCCFFA6;">(INNER) JOIN</mark>: Returns records that have matching values in both tables (default join)
* <mark style="background: #ADCCFFA6;">LEFT (OUTER) JOIN</mark>: Return all records from the left table, and the matched records from the right table
* <mark style="background: #ADCCFFA6;">RIGHT (OUTER) JOIN</mark>: Return all records from the right table, and the matched records from the left. Uncommon
* <mark style="background: #ADCCFFA6;">FULL (OUTER) JOIN</mark>: Returns all records when there is a match in either left or right table. Uncommon

## Example With One-To-One Table

| pets.name | VetName  |
| --------- | -------- |
| Pixel     | Vettison |
| Toby      | Ranarian |
| Goliath   | Maldoc   |
```MySQL
SELECT
	pets.name, humans.name as VetName
FROM pets
INNER JOIN humans
	ON pets.veterinarian_id = humans_id;
```
Leftmost table is always listed as the from, join as the right.

The way it works is putting all the columns into one big combined column. It then copies the left table data in, and then fills in all the vet ids that fit human ids. Then it selects the columns you asked for and rename the column because you asked it to be named VetName. Final query result is the table above

In a one-to-one table, the order you put the tables doesn't matter because there won't be any null values. Every entry has a corresponding foreign key

## Example with One-To-Many Table
```MySQL
SELECT
	pets.name, humans.name, pet_owners.adoption_date
FROM pet_owners
INNER JOIN pets
	on pet_owners.pet_id = pets.id
INNER JOIN humans
	on pet_owners.owner_id = humans.id;
```
The table names are pets, pet_owners, and humans. Other are column names. Good practice to include the name of the table even if there is no other column with the same name anywhere in the database

To order the data alphabetically, edit the last inner join to be
```MySQL
INNER JOIN humans
	on pet_owners.owner_id = humans.id ORDER BY pets.name;
```

## Left Joins
Remember the inventory database with item and store.
We want all the items in the items table and the quantity of each item at store 7. Want it to look like

| quantity | id  | SKU | type_id | department_id | MSRP | price | size | brand_id | supplier_id |
| -------- | --- | --- | ------- | ------------- | ---- | ----- | ---- | -------- | ----------- |

An example of a query that could do this is:
```MySQL
SELECT
	store_items.quantity, items.*
FROM
	items
LEFT JOIN store_items
	ON items.id = store_items.item_id
	AND store_items.store_id = 7;
```
List the items table first because you want all the items regardless of if they're in store 7's inventory. Gets ALL the items and then extra information depending on if store 7 has them
