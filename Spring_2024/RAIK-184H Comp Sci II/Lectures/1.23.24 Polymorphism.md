# Polymorphism 
**Polymorphism** is one of the three main tenets of OO programming.
Do x for a collection of various types of objects, where X is different depending on the type of object
"Old code using new code"
It is the process the compiler goes through to determine which version of an overridden function to run.

You should use override but technically it'll still default to the new declared method in the child first. (if it is of type child)
# Inheritance
In Java, the `extends` keyword is used in the class header to specify which preexisting class a new class is inheriting from
`public class Student extends Person`
Person is said to be
* the *parent* class of Student
* the *super* class of Student
* the *base* class of Student
* an *ancestor* of Student

Student would be known as child, sub, derived, descendant, etc

Student inherits all instance variables and instance methods of the super class. Additional methods can be added to class B to specialize. The child class can also replace (override) methods from super class.

The `super` keyword is used to specify you're referring to the parent class.
IN CONSTRUCTORS:
	MUST BE IN THE FIRST LINE OF CONSTRUCTOR
	If no parent constructor is explicitly called, the default, 0-parameter constructor of the parent is called. If no default constructor exists, a syntax error occurs.
	If a parent constructor is called, another constructor in the same class may not be called.
You cannot nest super calls (super.super.method()).
CAN ACCESS METHODS PREVIOUSLY OVERWRITTEN.

The Object class is the superest class. All classes are descendants of Object.
It contains a toString, equals, hashCode, clone, getClass

Any method that is not `final` may be overridden by descendant classes.

`protected` is an access modifier that makes the thing accessible by classes within the same package AND all descendant classes.
Instance variables should be private
protected methods are used to allow descendant classes to modify instance variables in ways other classes can't
## Relationships
The **Has-A** relationship is modeled by composition. The instance variables or fields internal to objects. This thing HAS A blank.

The **Is-A** relationship denotes some form of specialization. Not the same as Has-A. This thing IS A blank.
This nan be modeled by inheritance. Classes can inherit from other classes
