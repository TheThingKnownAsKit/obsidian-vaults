# BIG O NOTATION
<mark style="background: #ADCCFFA6;">Big-O notation</mark> provide a way to compare the number of operations required by 2 functions. Note, not ALL operations but the one important one
"f(n) is O(g(n))" means:
* the number of operations required to run algorithm f is less than or equal to the number of operations required to run algorithm g up to some constant factor for large values of n
* f(n) is O(g(n)) if there is a real constant c > 0 and an integer constant n_0 >= 1 such that f(n) <= c g(n), for n>= n_0
	* This n_0 is the first number of n such that the inequality is true. Usually a very large number since this only needs to be true for large numbers
	* n is usually the length of the array or input
	* c can be whatever constant you make up. Can be arbitrarily large

Making up numbers

Big-O <mark style="background: #BBFABBA6;">allows you to ignore constant factors and lower order or less dominant terms</mark>. For example:
$2n^2+5n-4$ is O($n^2$) because no one cares about the lower degree terms and constants are ignored

You could also do $2n-1$ is O($n^2$). It <mark style="background: #BBFABBA6;">ONLY matters that O is bigger than the original one</mark>. This one isn't very precise but it is valid

Big Theta and beta exist but don't matter right now. One is lower bound one is tightest bound. Big-O is upper bound. <mark style="background: #BBFABBA6;">Big-O provides a mechanism to precisely characterize functions according to typical function categories</mark>


## Logic Example
f(n) = 2n + 5
g(n) = n

Considering the condition 2n + 5 <= n. Will it ever hold it it's current state? No
If we add a constant to n to make it true, we get 2n + 5 <= 3n and this condition DOES hold as long as n is greater than or equal to 5

Therefore,
c = 3
n_0 = 5

## Function Categories
The constant function: f(n) = 1 where the simplified version is equal to a constant
The linear function: f(n) = n where the simplified version is equal to a linear variable
The quadratic function: f(n) = n^2 where the simplified version is equal to a quadratic variable
The cubic function: f(n) = n^3 where the simplified version is equal to a cubic variable 
The exponential function: f(n) = 2^n
The logarithm function: f(n) = logn, note this is always smaller than n. You only need to perform operations on just a few of n elements, like binary search. You do LESS operations than the length of the array n
The nlogn function: f(n) = nlogn

# SORTING ALGORITHMS REVIEW WITH BIG-O
<mark style="background: #ADCCFFA6;">Bubble sort</mark>: look at all the adjacent pairs of elements and swap them if they're out of order. Do this n times (where n is the length of the array)
```Java
static void bubblesort(int[] ar) {
	for i = 0 to ar.length {
		for j = 1 to ar.length {
			if (ar[j-1] > ar[j]) {
				swap(ar, j-1, j);
			}
		}
	}
}
```
Count for loops basically, its Big-O is n^2 and quadratic

<mark style="background: #ADCCFFA6;">Selection sort</mark>: look at all unsorted elements, find the minimum element, swap it to be in the last position of the sorted list, then move the boundary for the sorted list up one element so you don't evaluate anything before it
```Java
static void selectionsort(int[] ar) {
	for i = 0 to ar.length {
		for j = 1 to ar.length - 1 {
			if (ar[j] < ar[i]) {
				swap(ar, j, i);
			}
		}
	}
} // Self written might not be right
```
Its Big-O is n^2 because it'd have two for loops. It is quadratic
