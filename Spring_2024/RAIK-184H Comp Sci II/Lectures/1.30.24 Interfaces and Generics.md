# INTERFACES
Interfaces are assumed to be public because they can't be anything else 
Constants must be static

Commonly start with I

```java
public class MyClass extends AnotherClass implements MyInterface {
	// define class here, implement all the abstract methods
	public void myFunctionName(){
		//stuff
	}
}
```

You can *technically* declare the type of an object as an interface but it must be instantiated as something else
* ONLY do this if you plan on ONLY using stuff from the interface. No new methods or functionality
Example:
```java
interface Printable {
	void print();
}

class Greeter implements Printable {
	public void print() {
		System.out.println("Hello");
	}
	
	public static void main(String args[]) {
		Printable greeter = new Greeter(); //Okay, best practice even
		greeter.print();
	}
}
```

**It is best practice to use the most general form of something you can.**
It is very common for your dynamic type and declared type to be different
	Declared is first, dynamic is second/instantiated

Implemented methods from interfaces HAVE to be public or the method signatures won't match and the compiler will think you haven't implemented the required methods
	Every method declared in an interface is implicitly public

|  | Interface | Abstract Class |
| ---- | ---- | ---- |
| Fields | Only constants | Constants and variable data |
| Methods | No implementation allowed (no abstract modifier necessary (exceptions but uncommon)) | Some implementation allowed (functions can be abstract or concrete) |
| Inheritance | A subinterface can extend numerous interfaces | A subclass can extend only one class |
| Implement Interfaces | Cannot implement any interfaces | Can implement numerous interfaces |
| Extending | Cannot extend a class because it is not a class | Extends one class |
| Root | none | Object (of all classes) |
| Names | Adjective or Nouns (usually start with I) | Nouns |
