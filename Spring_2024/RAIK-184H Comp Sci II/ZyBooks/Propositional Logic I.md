A **proposition** is a statement that is either true or false. A proposition's **truth value** is a value indicating whether the proposition is actually true or false (can be unknown/matter of opinion if it's a bad proposition)

A **compound proposition** is created by connecting individual propositions with logical operations

A compound proposition that uses a conditional operation is called a **conditional proposition**. Expressed in English is a conditional statement. In the conditional proposition $p\to q$, the proposition p is called the **hypothesis** and the proposition q is called the **conclusion**
	If the hypothesis is false, the conditional statement must be true
	Otherwise, the conclusion must be consistent with the hypothesis to be true
Switching the variables creates a **converse**
	Original: $x\to y$
	Converse: $y\to x$
Negating the variables creates an **inverse**
	Original: $x\to y$
	Inverse: $\lnot x\to \lnot y$
Negating and switching the variables creates a **contrapositive**
	Original: $x\to y$
	Inverse: $\lnot y\to \lnot x$

A compound proposition is a **tautology** if the proposition is always true, regardless of the individual propositions that occur in it. It is a **contradiction** if it is always false
