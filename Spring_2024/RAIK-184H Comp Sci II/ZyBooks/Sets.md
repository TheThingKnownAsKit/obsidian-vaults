# SETS AND SUBSETS
A **set** is a collection of objects. The objects are called **elements**. It can contain many different types of elements, not just one specific type

The **roster notation** definition of a set is a list of the elements enclosed in curly braces with the individual elements separated by commas
	Literal array definition
	You can redefine a set in a different order as long as all the original elements are present + any new ones

In **set builder notation**, a set is defined by specifying that the set includes all elements in a larger set that also satisfy certain conditions
![[Pasted image 20240212111950.png]]

Sets can equal each other as long as they contain the same elements. Order does not matter

Epsilon is used to indicate that an element is in a set: $2\epsilon A$
An epsilon with a dash through it indicates iit is not in a set

A **finite set** can be numbered 1 through n for some positive int n
An **infinite set** is a set that is not finite
The **universal set**, usually denoted by union, is a set that contains all elements mentioned in a particular context (e.g. all ints, all positive ints)

the **cardinality** of a finite set is the number of distinct elements in A

# SETS OF SETS
The **power set** of a set A, denoted P(a), is the set of all subsets of A. All possible combinations of current elements
	A = {1, 2, 3}
![[Pasted image 20240212115349.png]]
Cardinality of power sets is 2^set cardinality
	If |A| = 3, the cardinality of it's power set is $2^3=8$
