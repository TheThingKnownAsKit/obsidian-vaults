## Normality
The <mark style="background: #ADCCFFA6;">Shapiro-Wilk Test</mark>is a goodness-of-fit score for how well each data point fits to a normal distribution
	You take the ordered data and compare against the expected point on that part of a normal distribution (given by the "a" terms that are derived from the position and covariance)
$$W=\frac{(\sum\limits^n_{i=1}a_ix_i)^2}{\sum\limits^n_{i-1}(x_i-\overline{x})^2}=\frac{m^TV^{-1}}{(m^TV^{-1}m)^{1/2}}$$
We will not actually have to calculate these, use Excel or Python
In python, use `scipy.stats.shapiro` https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.shapiro.html
You can also use it in excel if you want but just use Python

Anderson-Darling and Kolmogorv-Smirnov do similar things but we're not using them

<mark style="background: #BBFABBA6;">The null hypothesis for all normality tests is that your data is normally distributed. Thus, a p >= 0.05 suggests you can use t-tests</mark>

## Non-Parametric Tests
<mark style="background: #ADCCFFA6;">Non-parametric</mark> tests are those that do NOT make assumptions about the parameters or shape of the distribution. Basically you use it if your distribution is not normal

- The <mark style="background: #ADCCFFA6;">Wilcoxon Signed-Rank test</mark> is an alternative to paired t-tests
	- It applies ranking so that as long as the data is ordinal (able to be ordered), you can use rankings
	- STEPS:
1. Get the deltas (pre-post). NOTE THE ORDER OF THIS DEPENDS ON WHAT YOU WANT TO GO UP
2. Get the ordered absolute deltas  (use average rank for tie cases). Order them based on their absolute value basically
![[Pasted image 20241113155148.png]]
3. Sign the ranks based on the direction of change (if there's no different you'll see both positive and negative high ranking values to cancel each other out)
![[Pasted image 20241113155242.png]]
The hypothesis is basically H0: there is no different in rank sums or Ha: there is a difference. Calculate it using the W statistic (some sources use T)
$$W=min(\text{sum of positive ranks},\text{sum of negative ranks})$$
![[Pasted image 20241113155438.png]]
4. Compare this to the expected value of the W statistic. We expect half positive half negative, so p = 0.5
$$E(W^+)=E(W^-)=\sum\limits^n_{i+1}i*0.5=\frac{n(n+1)}{2}$$
5. Ignore the original data and use rankings in a normal distribution. The sum is only included in the case of ties
$$\mu_W=\frac{n(n+1)}{4}$$
$$z=\frac{W-\mu_W}{\sigma_W}$$
$$\sigma_{W^2}=\frac{n(n+1)(2n+1)-\sum\limits^k_{i=1}\frac{t_i^3-t_i}{2}}{24}$$
![[Pasted image 20241113160337.png]]
This z-score yields = 0.0244 for a one-tailed test. The repetitive behaviors were statistically significantly reduced
Note: Only use z-table when there are more than 30 samples. Otherwise use the W statistic directly from critical values. Reject null hypothesis if the W statistic is less than the critical value

To do this in python, use `scipy.stats.wilcoxon`
```Python
import scipy
x = [85,70,40,65,80,75,55,20]
y = [75,50,50,40,20,65,40,25]
scipy.stats.wilcoxon(x,y,alternative="greater",method="approx)

# Will get an error that the sample size is not > 30. Use this for small
scipy.stats.wilcoxon(x,y,alternative="greater",method="exact)
```

- The <mark style="background: #ADCCFFA6;">Mann-Whitney U-test</mark> is an alternative to unpaired t-tests. The basic idea is the same as Wilcoxon. You are looking to see if there's a difference in the rank sum of two test
![[Pasted image 20241113163124.png]]
Sum the ranks present in each set
The<mark style="background: #ADCCFFA6;">U statistic</mark> is a minimum of U1 and U2, which are:
$$U_1=n_1*n_2+\frac{n_1*(n_1+1)}{2}-T_1$$
$$U_2=n_1*n_2+\frac{n_2*(n_2+1)}{2}-T_2$$
Then,
$$U=min(U_1,U_2)$$
![[Pasted image 20241113163331.png]]
$$\mu_U=\frac{n_1*n_2}{2}$$
$$\sigma_U=\sqrt{\frac{n_1*n_2*(n_1+n_2+1)}{12}}$$
$$Z=\frac{U-\mu_U}{\sigma_U}$$
Only use for larger sample size (20 or 25), otherwise read the U statistic directly from the table of critical values
You can use `scipy.stats.mannwhitneyu` in python
