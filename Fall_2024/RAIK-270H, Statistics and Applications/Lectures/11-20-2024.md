## Variance
Literally how much it varies
$$var_s=\frac{\sum\limits_{i=1}^n(x_i-\overline{x})^2}{n-1}$$

## Covariance
<mark style="background: #ADCCFFA6;">Covariance</mark> is how values vary WITH EACH OTHER. It is similar to variance except it considers two features rather than just one
	Children's age and height have strong covariance, they both go up

Rather than square the difference from the mean, we multiply the difference from the mean by the difference for the other
$$\text{covar}_p(x,y)=\frac{\sum\limits^n_{i=1}(x_i-\overline{x})*(y_i-\overline{y})}{n}$$
$$\text{covar}_s(x,y)=\frac{\sum\limits^n_{i=1}(x_i-\overline{x})*(y_i-\overline{y})}{n-1}$$

You usually arrange these into a <mark style="background: #ADCCFFA6;">covariance matrix</mark>. It is a symmetric matric where the upper right half is the same as the lower half

|            | Age (A) | Weight (W) | Height (H) |
| ---------- | ------- | ---------- | ---------- |
| Age (A)    | 60      | 16.9       | 78.85      |
| Weight (W) | 16.9    | 5.6        | 25.88      |
| Height (H) | 78.85   | 25.88      | 119.55     |
This is a population matrix. Same concept for sample

In Excel, you can use Data -> Data Analysis -> Covariance. Note that this only calculates population
	Can also use COVARIANCE.P and COVARIANCE.S
Python has `numpy.cov` and `scipy.stats.Covariance`

<mark style="background: #BBFABBA6;">Covariance for two features is dependent on the units</mark>. They must be in comparable or the same units

## Correlation
You will compute the <mark style="background: #ADCCFFA6;">correlation coefficients</mark> to see if covariance is $$\rho_{A,B}=corrA,B=\frac{cov(A,B)}{\sigma_A\sigma_B}$$
The same for population and sample data because the correlation values does not take into account the number of data points you have

Note: $\rho$ is `\rho` pronounced like row. Usually means population correlation coefficient (with r being used for sample) but it doesn't matter because the equation is the same
	Usually $\sigma$ is for population and s is for sample standard deviation but it doesn't matter in this class not really

To compute the standard deviation from our covariance matrices, just <mark style="background: #BBFABBA6;">take the square root of the diagonal values, which are the regular variances</mark>

|         | Age(A) | Weight (W) | Height (H) |
| ------- | ------ | ---------- | ---------- |
| stdev_p | 7.75   | 2.37       | 10.93      |
| stdev_s | 8.49   | 2.60       | 11.98      |
