## Linear Regression
Using the <mark style="background: #ADCCFFA6;">linear regression</mark> you build directly from the covariance matrix. Basically just making a line through the covariance trends.
	You can apply it to any data but it's not always worth it or fitting. It can't handle non-linear relationships or not easily separated/modeled with a line data

* Create a line of the form y = mx + b
	* The slope of the line, m, is given as the covariance of x with y divided by the variance of x
	* The intercept, b, is given by the average y-offset given by yi-m*x
$$m=\frac{\sum\limits^n_{i=1}(x_i-\overline{x})*(y_i-\overline{y})}{\sum\limits^n_{i=1}(x_i-\overline{x})*(x_i-\overline{x})}$$
$$b=\frac{\sum\limits^n_{i=1}y_i-(m*x_i)}{n}$$

<mark style="background: #BBFABBA6;">Use correlation to calculate the goodness of fit of the line</mark>. This is $R^2$. For example, the correlation between Age and Height was 0.93 so the squared value of this is about 0.86 which is R^2

R^2 is based on the correlation matrix and does not account for the number of samples in the data set. The confidence of our slope is only as good as the number of data points. This is why you find the <mark style="background: #ADCCFFA6;">Adjusted R-Squared, AdjR^2</mark> to account for this
$$AdjR^2=1-\frac{(1-R^2)(n-1)}{n-k-1}$$
Where:
* n = number of data points
* k = number of variables we are considering besides the constant
* Note that this simplifies to 1 when R^2 is 1

<mark style="background: #ADCCFFA6;">Residuals</mark> are basically errors

use `pip install scikit-learn` https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html
Create the model as an object using `.fit()`, get the R^2 with `.score()`, obtain the slopes with `.coef_` and intercept with `.intercept_`

Multi dimensional regression example
```Python
import numpy as np
from sklearn.linear_model import LinearRegression
X = np.array([[1, 1], [1, 2], [2, 2], [2, 3]])
# y = 1 * x_0 + 2 * x_1 + 3 = array([ 6, 8, 9, 11])
y = np.dot(X, np.array([1, 2])) + 3
reg = LinearRegression().fit(X, y)
reg.score(X, y)
# Output: 1.0
reg.coef_
# Output: array([1., 2.])
reg.intercept_
# Output: 3.0...
reg.predict(np.array([[3, 5]]))
# Output: array([16.])
```

2d example
```Python
>>> import numpy as np
>>> from sklearn.linear_model import LinearRegression
>>> X = np.array([[1, 1], [1, 2], [2, 2], [2, 3]])
>>> # y = 1 * x_0 + 2 * x_1 + 3 = array([ 6, 8, 9, 11])
>>> y = np.dot(X, np.array([1, 2])) + 3
>>> reg0 = LinearRegression().fit(X[:,0].reshape(-1,1), y)
>>> # .reshape(-1,1) nests the array in a column matrix; the -1 makes numpy guess size, or you could pass number of rows
>>> reg0.score(X[:,0].reshape(-1,1), y)
>>> 0.6923
>>> reg1 = LinearRegression().fit(X[:,1].reshape(-1,1), y) >>> reg1.score(X[:,1].reshape(-1,1), y)
>>> 0.9615
```
