<mark style="background: #ADCCFFA6;">Combinatorics</mark> is the field of math concerned with counting

<mark style="background: #ADCCFFA6;">Multiplication rule of counting</mark> if an event can occur in x ways and another event can occur in y ways, the number of possible ways that both events can occur is x * y
	Used to calculate digit possibilities

<mark style="background: #ADCCFFA6;">Permutations</mark> consider possible orderings of a set of objects. UNIQUE combinations
	Generally, if you have n choices at the first step, you will have n - 1 in the next. This means most permutations have n! unique orderings

<mark style="background: #ADCCFFA6;">Sub-Permutations</mark> are used if not all objects are used in the ordering 
$P_{n,k}=\frac{n!}{(n-k)!}$
For example, how many 4 digit numerical passcodes are there where no number is repeated in the code
