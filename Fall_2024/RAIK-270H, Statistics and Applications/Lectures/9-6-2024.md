## Descriptive Statistics
Tables are great for raw data but if it's a lot of data it gets hard to comprehend real fast
Visualization will help with this, but you will still want numerical descriptors for statistical analysis

<mark style="background: #ADCCFFA6;">Simple descriptors</mark> so simple I don't really understand how to describe it. I think it's like 20%, etc
<mark style="background: #ADCCFFA6;">Histograms</mark> take raw data and put it into bins representing ranges of values along x and heights representing counts in y. Similar to a bar graph but it is RANGES

Mean is the average 
The median is the value in the middle. For even, it is the value in between the two middle numbers (average middle two)
Mode is the most common value in a dataset (if there is a tie it is multi-modal). Works on categorical data

<mark style="background: #ADCCFFA6;">Quartiles</mark> are four groups of increasing 25% into which data can be evenly divided. 25% -> 50% -> 75% -> 100%
1. First quartile is the value at 25% and down the sorted list
2. The second quartile is the middle of the sorted list of values (median)
3. Third is 75% down the sorted list of values
4. 0 and 4 are the minimum and maximum
Easiest way to do this is split in half around the median, excluding the median, and find the median of each half for Q1 and Q3 (the median itself is Q2). This is <mark style="background: #ADCCFFA6;">traditional</mark>

	Q1 = .25*(n+1) = 2.5
	Q3 = .75*(n+1) = 7.5
	If index is whole number, select directly. If index is fractional, average numbers on either side

We square it because:
1. We don't care if the value is below or above the mean
2. We want to exacerbate the huge differences from the mean

<mark style="background: #ADCCFFA6;">Standard Deviation</mark> is the square root of the variance
![[Pasted image 20240906163657.png]]
We take the square root because we had square the difference. Puts it back into the original units (if you square minutes it isn't minutes anymore, so you have to take the square root)

If you pick your data at random, and it follows a bell-shaped curve (normal distribution), <mark style="background: #BBFABBA6;">68.2% of your data will be within 1 standard deviation on either side and 95% will be within 2 stdevs</mark>
